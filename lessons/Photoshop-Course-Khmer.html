💻 Code៖ បង្កើត Document ដោយ Script

🧩 របៀប Code ជំហានៗ

  2. UnitValue(1080, 'px') — ទំហំជា Pixel · 72 = ppi សម្រាប់អេក្រង់។
  3. NewDocumentMode.RGB — Color mode · ប្តូរជា CMYK ពេលបោះពុម្ព។
  4. alert() — បង្ហាញសារ។ Script អាចបង្កើត Document ១០០ ក្នុងមួយវិនាទី — ល្អសម្រាប់ការងារដដែលៗ។
