១. UI Design Style ជាអ្វី?

UI style = «ភាសារូបរាង» របស់ App/Website — ពណ៌ Radius ស្រមោល Blur Border Font។ App ដដែល អាចមានអារម្មណ៍ខុសគ្នាស្រឡះ (ទុកចិត្ត · សប្បាយ · ប្រណីត · Tech)។ វគ្គនេះមាន Style ១៦ — នីមួយៗមាន អេក្រង់ App ពិត (HTML/CSS) ប្រវត្តិ (អ្នកណាបង្កើត) លក្ខណៈ វិធីធ្វើក្នុង Figma Accessibility និងលំហាត់។ ជាវគ្គបន្ថែមលើវគ្គ UX/UI Design (Research → Wireframe → Prototype)។

មេរៀន ១UX vs UI និងច្បាប់ UX សំខាន់ៗ

UX (User Experience) = បទពិសោធន៍ — ងាយប្រើ? រកឃើញ? លឿន? · UI (User Interface) = រូបរាង — ពណ៌ Font ប៊ូតុង ស្រមោល។ UI Style ប្តូរ «សំលៀកបំពាក់» តែ UX ល្អត្រូវនៅដដែល — ឧទាហរណ៍ App «My Wallet» ក្នុងវគ្គនេះ មានរចនាសម្ព័ន្ធដដែលក្នុង Style ទាំង ១៦។ ពាក្យ «User Experience» ល្បីដោយ Don Norman នៅ Apple (1993)។

✍️ លំហាត់ ១

ហេតុអ្វីប៊ូតុង «Pay» ក្នុង App ទូរស័ព្ទ គួរធំ និងនៅខាងក្រោមអេក្រង់?

មើលចម្លើយ

ច្បាប់ Fitts — គោលដៅធំ និងជិតមេដៃ (តំបន់ខាងក្រោម «thumb zone») ចុចបានលឿន និងមិនសូវខុស។

មេរៀន ២Design system: Token · Component · State

Style ណាក៏ដោយ ត្រូវសង់ជា Design system៖ Tokens (តម្លៃតូចៗដែលប្រើឡើងវិញ) → Components (ប៊ូតុង Card Input Switch Nav) → Patterns (Login, Checkout)។ ប្តូរ Style = ប្តូរ Token ភាគច្រើន!

មេរៀន ៣Skeuomorphism — ធ្វើត្រាប់វត្ថុពិត

📱 អេក្រង់ App ឧទាហរណ៍ — សង់ពិតដោយ HTML/CSS (មិនមែនរូបថត) · មើល CSS ពេញក្នុង UI Style Lab ចុងវគ្គ

ហេតុអ្វី Apple ឈប់ប្រើ Skeuomorphism ក្នុង iOS 7 (2013)?
