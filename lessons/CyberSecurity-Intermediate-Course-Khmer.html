✍️ លំហាត់ ២

Hash និង Encryption ខុសគ្នាដូចម្តេច?

មើលចម្លើយ

Hash = មួយទិស (មិនអាចបង្វិល) · Encryption = ពីរទិស (មាន Key ទើប Decrypt បាន)។

មេរៀន ៣រក្សាទុកពាក្យសម្ងាត់ — Salt + PBKDF2

លទ្ធផលពិត · Python 3
Salt: 5c533defe51ac877… Hash: 18f765b9ceecb1475cf77066…
Login ត្រូវ: True · ខុស: False
Salt ខុសគ្នា → Hash ខុសគ្នា សម្រាប់ពាក្យដូចគ្នា: True
🧩 ពន្យល់ជំហានៗ
  1. កុំរក្សាទុក Password ជាអក្សរធម្មតា ឬ MD5/SHA1 សុទ្ធ។
  2. ប្រើ Salt (ចៃដន្យ) + KDF យឺត (Argon2id, bcrypt, scrypt, PBKDF2)។
  3. hmac.compare_digest ការពារ Timing attack។

លទ្ធផលពិត · Python 3

  2. ការពារ៖ Escape output តាមបរិបទ · Framework ទំនើប (React) Escape ស្វ័យប្រវត្តិ · ជៀស innerHTML ជាមួយទិន្នន័យអ្នកប្រើ · CSP · Cookie HttpOnly។
