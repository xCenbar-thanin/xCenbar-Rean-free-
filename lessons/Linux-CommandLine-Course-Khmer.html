២. របៀបដំឡើង (Windows/macOS + VS Code)

Windows: WSL (Windows Subsystem for Linux)

  1. បើក PowerShell ជា Administrator ហើយវាយ wsl --install → Restart (ដំឡើង Ubuntu ដោយ Default)
  2. បើក Ubuntu ពី Start menu → កំណត់ Username/Password (Password មិនបង្ហាញពេលវាយ — ធម្មតា)
  3. ដំឡើង Windows Terminal (មានស្រាប់ក្នុង Windows 11)

macOS / Linux

macOS មាន Terminal ស្រាប់ (Shell zsh ស្រដៀង Bash — ពាក្យបញ្ជាភាគច្រើនដូចគ្នា)។ Linux Desktop៖ Ctrl+Alt+T។

VS Code

  1. Extension WSL (Microsoft) → ក្នុង Ubuntu វាយ code . → VS Code បើក Folder ក្នុង Linux
  2. Extension Remote - SSH → ភ្ជាប់ទៅ Server (VPS) ហើយកែ File ដូចនៅកុំព្យូទ័រ
  3. Terminal ក្នុង VS Code៖ Ctrl+` · Extensions៖ ShellCheck (ពិនិត្យ Bash script), Bash IDE
  4. Server ពិតសម្រាប់ហាត់៖ VPS ថោកៗ (DigitalOcean, Vultr, Hetzner) ឬ Ubuntu ក្នុង VirtualBox/Multipass

🏁 លំហាត់គម្រោងចុងក្រោយ

  1. ជួល VPS តូច (ឬប្រើ Multipass/VirtualBox) ដំឡើង Ubuntu LTS
  2. ធ្វើជំហាន 1–4 ហើយបើក https://your-domain/api/health បាន

  5. Script report.sh វិភាគ /var/log/nginx/access.log ប្រចាំថ្ងៃ
  6. (បន្ថែម) GitHub Actions ហៅ deploy តាម SSH ពេល Push ទៅ main
