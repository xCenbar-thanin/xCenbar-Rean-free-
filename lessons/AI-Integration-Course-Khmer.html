២. របៀបដំឡើងក្នុង VS Code

  1. ដំឡើង Node.js 22 LTS ឬថ្មីជាង
  2. ចុះឈ្មោះ Claude Console (platform.claude.com) → API Keys → Create Key → ចម្លង sk-ant-... (បង្ហាញតែម្តង!)
  3. បង្កើតគម្រោង ហើយដាក់ Key ក្នុង .env (បន្ថែម .env ទៅ .gitignore)
  4. VS Code Extensions៖ DotENV (Highlight .env) · REST Client ឬ Thunder Client (សាក API) · Claude Code (AI ជំនួយសរសេរកូដ — ជម្រើស)
⚠️ API key = លុយ។ កុំដាក់វាក្នុង Frontend (React/Browser), កុំ Commit ទៅ GitHub។ ហៅ API តែពី Server (Route Handler, Server Action, Backend) ប៉ុណ្ណោះ។ កំណត់ Spend limit ក្នុង Console។
ℹ️ អំពីលទ្ធផលក្នុងវគ្គនេះ៖ ម៉ាស៊ីនបង្កើតវគ្គមិនអាចភ្ជាប់ Claude API ពិតទេ។ ដូច្នេះកូដ JavaScript ត្រូវបានរត់ពិតក្នុង Node.js 22 តែភ្ជាប់ទៅ Mock server (ANTHROPIC_BASE_URL=http://127.0.0.1:4010) ដែលមានទម្រង់ Request/Response, Headers, Errors, Streaming events និង Tool use ដូច API ពិត ប៉ុន្តែ ចម្លើយបង្កើតដោយច្បាប់សាមញ្ញ មិនមែន AI ពិត។ នៅលើម៉ាស៊ីនអ្នក លុប ANTHROPIC_BASE_URL ហើយ Claude ពិតនឹងឆ្លើយ (ឆ្លាតជាងនេះច្រើន)។ ការប្រើ Mock បែបនេះក៏ជាបច្ចេកទេសល្អសម្រាប់ Tests ដែរ (មេរៀន ១៤)។

៣. ពន្យល់ធាតុនីមួយៗ (Elements)

ពាក្យអត្ថន័យ
Tokenបំណែកអត្ថបទដែលម៉ូដែលអាន/សរសេរ (ពាក្យ ឬផ្នែកនៃពាក្យ)។ តម្លៃ API គិតតាម Token។ អក្សរខ្មែរប្រើ Token ច្រើនជាងអង់គ្លេសសម្រាប់អត្ថន័យដូចគ្នា
Context windowចំនួន Token អតិបរមាដែលម៉ូដែលអានបានក្នុងពេលតែមួយ (Prompt + ប្រវត្តិ + ចម្លើយ) — ម៉ូដែល Claude បច្ចុប្បន្ន 1M tokens
MessagesArray នៃ { role: "user" | "assistant", content } — ប្រវត្តិសន្ទនា
System promptការណែនាំទូទៅ (តួនាទី, ច្បាប់, ទម្រង់ចម្លើយ)
max_tokensចំនួន Token ចម្លើយអតិបរមា
Streamingទទួលចម្លើយជាបំណែកៗ (SSE) ដូចការវាយអក្សរ
Tool useម៉ូដែលស្នើហៅ Function របស់អ្នក (ឧ. get_menu) ហើយអ្នករត់វា
Structured outputបង្ខំចម្លើយជា JSON តាម Schema
EmbeddingVector (លេខរាប់រយ) តំណាងអត្ថន័យនៃអត្ថបទ — ប្រើស្វែងរកតាមអត្ថន័យ
RAGRetrieval-Augmented Generation — រកឯកសារពាក់ព័ន្ធ ហើយដាក់ក្នុង Prompt
AgentLoop៖ ម៉ូដែលគិត → ហៅ Tool → មើលលទ្ធផល → បន្ត រហូតបញ្ចប់ការងារ
Hallucinationម៉ូដែលបង្កើតព័ត៌មានមិនពិតដោយទំនុកចិត្ត — កាត់បន្ថយដោយ RAG, Tools, Evals

មេរៀន ១១ Agents & Model Context Protocol (MCP)

Agent = LLM + Tools + Loop (ដូចមេរៀន ៦) ដែលធ្វើការងារច្រើនជំហានដោយខ្លួនឯង៖ «រក Orders មិនទាន់ដឹក → ពិនិត្យស្តុក → ផ្ញើសារទៅអតិថិជន»។ ចាប់ផ្តើមពីសាមញ្ញ — Workflow ថេរ (Prompt chaining) ច្រើនតែគ្រប់គ្រាន់ មុនពេលត្រូវការ Agent ពេញលេញ។

Patternពន្យល់

Routingចាត់ថ្នាក់សំណួរ → ផ្ញើទៅ Prompt/Model ត្រឹមត្រូវ (Haiku សម្រាប់សាមញ្ញ)
