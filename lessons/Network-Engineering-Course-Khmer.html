មេរៀន ៣Ethernet · MAC · Switching

MAC address = 48 bit (ឧ. 3C:22:FB:9A:10:7E) — ៣ byte ដំបូង = ក្រុមហ៊ុនផលិត (OUI)។ Switch រៀន MAC address table៖ ពេល Frame ចូល Port ណា វាចាំ MAC ប្រភព ↔ Port នោះ។

ពាក្យន័យ
Collision domainSwitch ៖ មួយ Port = មួយ Domain (Full-duplex)
Broadcast domainVLAN មួយ = មួយ Broadcast domain · Router បំបែក
ARPស្វែងរក MAC ពី IP (Who has 192.168.1.1?)
STP (802.1D)ការពារ Loop ពេលមាន Switch ភ្ជាប់ច្រើនផ្លូវ — Radia Perlman (1985)
🧩 ពន្យល់ជំហានៗ
  1. PC-A (MAC A, Port 1) ផ្ញើទៅ PC-B
  2. Switch រៀន៖ A → Port 1
  3. Switch មិនទាន់ស្គាល់ B → Flood ទៅ Port ទាំងអស់ (លើកលែង Port 1)
  4. PC-B ឆ្លើយ → Switch រៀន B → Port 3
  5. លើកក្រោយ A → B ផ្ញើទៅ Port 3 តែមួយ (Forward)

✍️ លំហាត់ ៣

ពេល Switch ទទួល Frame ទៅ MAC ដែលវាមិនទាន់ស្គាល់ វាធ្វើអ្វី?

មើលចម្លើយ

Flood — ផ្ញើចេញគ្រប់ Port ក្នុង VLAN ដដែល (លើកលែង Port ដែលចូល)។ ពេលម៉ាស៊ីនគោលដៅឆ្លើយ Switch រៀន MAC នោះ។

✍️ លំហាត់ ៣.២

MAC address មានប៉ុន្មាន bit? ផ្នែកដើម ២៤ bit ជាអ្វី?

មើលចម្លើយ

48 bit (12 Hex) · ២៤ bit ដើម = OUI (អ្នកផលិត)។

មេរៀន ៦VLAN & Trunk (802.1Q)

VLAN បំបែក Switch មួយជា Network ឡូហ្សិកច្រើន (ឧ. សិស្ស · គ្រូ · កាមេរ៉ា) — សុវត្ថិភាព និងកាត់ Broadcast។ Trunk ដឹក VLAN ច្រើនលើខ្សែមួយ ដោយ Tag 802.1Q។ VLAN ផ្សេងគ្នាត្រូវការ Router/Layer-3 switch (Inter-VLAN routing) ដើម្បីនិយាយគ្នា។

✍️ លំហាត់ ៦

Port ដែលភ្ជាប់ PC សិស្ស គួរ Mode អ្វី? Port ដែលភ្ជាប់ Switch មួយទៀត?

✍️ លំហាត់ ៦.២

✍️ លំហាត់ ៦.៣
