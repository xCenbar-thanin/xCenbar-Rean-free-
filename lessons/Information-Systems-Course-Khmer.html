💡 As-is (ដំណើរការបច្ចុប្បន្ន) → រកចំណុចយឺត (Bottleneck) ធ្វើដោយដៃស្ទួន → To-be (ដំណើរការថ្មី)។ BPMN 2.0 ដោយ OMG (2011)។

✍️ លំហាត់ ៦

ដំណើរការអនុម័តប្រាក់ខែបន្ថែម ត្រូវចុះហត្ថលេខា ៥ នាក់ លើក្រដាស ចំណាយ ៣ សប្តាហ៍។ IS អាចកែយ៉ាងម៉េច?

មើលចម្លើយ

គូរ As-is ក្នុង BPMN → ស្វ័យប្រវត្តិ Workflow អនុម័តអេឡិចត្រូនិក (ជូនដំណឹង · អនុម័តស្របគ្នា · Deadline · Audit log) → To-be ពី ៣ សប្តាហ៍ មក ២–៣ ថ្ងៃ។

✍️ លំហាត់ ៦.២

BPMN៖ Event, Activity, Gateway, Pool/Lane គូរម៉េច?

មើលចម្លើយ

Event = រង្វង់ · Activity = ចតុកោណមុំមូល · Gateway = ពេជ្រ · Pool/Lane = ជួរតួនាទី។

✍️ លំហាត់ ៦.៣

As-is និង To-be process?

មើលចម្លើយ

As-is = ដំណើរការបច្ចុប្បន្ន · To-be = ដំណើរការកែលម្អ (ស្វ័យប្រវត្តិ តិចជំហាន)។

✍️ លំហាត់ ៦.៤

គូរ To-be សម្រាប់ «សុំច្បាប់ឈប់» ក្នុងប្រព័ន្ធ HR។

មើលចម្លើយ

Start → បុគ្គលិកដាក់ Form Online → Gateway: ថ្ងៃ ≤ 3? → ប្រធានផ្នែកអនុម័ត / >3 → HR អនុម័តបន្ថែម → Email ជូនដំណឹង → End។
