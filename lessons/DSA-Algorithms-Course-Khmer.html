មេរៀន ១Algorithm & Big-O៖ វាស់ល្បឿនកូដ

Algorithm = ជំហានច្បាស់លាស់ដើម្បីដោះស្រាយបញ្ហា។ Big-O ប្រាប់ថា ពេលទិន្នន័យ (n) កើនឡើង ការងារកើនលឿនប៉ុណ្ណា — មិនមែនវាស់វិនាទីទេ។

Big-Oឈ្មោះឧទាហរណ៍n=1,000,000
O(1)Constantយកធាតុ a[5] · dict lookup1
O(log n)LogarithmicBinary search≈ 20
O(n)Linearស្វែងរកម្តងមួយៗ1,000,000
O(n log n)LinearithmicMerge/Quick sort≈ 20,000,000
O(n²)QuadraticLoop ក្នុង Loop (Bubble sort)10¹²
O(2ⁿ)Exponentialសាកគ្រប់ជម្រើសមិនអាចគណនាបាន
លទ្ធផលពិត · Python 3
n=   10  O(log n)=  3  O(n)=    10  O(n²)=      100
n=  100  O(log n)=  6  O(n)=   100  O(n²)=    10000
n= 1000  O(log n)=  9  O(n)=  1000  O(n²)=  1000000
💡 ច្បាប់ Big-O៖ (1) បោះចោលថេរ — O(2n) = O(n) (2) យកផ្នែកធំបំផុត — O(n² + n) = O(n²) (3) Loop ជាប់គ្នា បូក · Loop ក្នុង Loop គុណ។

✍️ លំហាត់ ១

កូដមាន Loop for i in range(n) ហើយក្នុងនោះមាន Binary search លើ List ទំហំ n។ Big-O ជាអ្វី?

មើលចម្លើយ

O(n log n) — Loop n ដង × Binary search O(log n) មួយដងៗ។

✍️ លំហាត់ ១.២

កូដមាន Loop ពីរជាប់គ្នា (មិនមែនក្នុងគ្នា) នីមួយៗរត់ n ដង។ Big-O ប៉ុន្មាន?

មើលចម្លើយ

n + n = 2n → O(n) (ចោលថេរ 2)។

✍️ លំហាត់ ១.៣

រៀបលំដាប់ពីលឿនទៅយឺត៖ O(n²), O(1), O(n log n), O(log n), O(n)

មើលចម្លើយ

O(1) < O(log n) < O(n) < O(n log n) < O(n²)

✍️ លំហាត់ ១.៤

Algorithm O(n²) ចំណាយ 1 វិនាទីលើ n = 1,000។ បើ n = 10,000 ប្រហែលប៉ុន្មាន?

មើលចម្លើយ

n កើន ×10 → n² កើន ×100 → ប្រហែល 100 វិនាទី។

🎯 សំណួរជ្រើសរើស (ចុចចម្លើយ)

២. Loop ក្នុង Loop (n × n)?

💡 ជុំខាងក្នុង n ដង សម្រាប់ជុំខាងក្រៅនីមួយៗ → n·n។

៣. Big-O ពិពណ៌នាអ្វីជាចម្បង?

💡 Big-O មើលអត្រាកើនឡើង (Growth rate) មិនមែនវិនាទីពិតទេ។

មេរៀន ២Array & String · Two pointers

Array (Python list) រក្សាធាតុជាប់គ្នាក្នុង Memory → ចូលដោយ Index O(1) តែ បញ្ចូល/លុបកណ្តាល O(n) (ត្រូវរុញធាតុ)។ បច្ចេកទេស Two pointers ប្រើម្រាមដៃ ២ ពីចុងទាំងពីរ — កាត់ពី O(n²) មក O(n)។

មើលចម្លើយ

ព្រោះ List តម្រៀបរួច — បើផលបូកតូចពេក រំកិល i ទៅស្តាំ (ធំឡើង) បើធំពេក រំកិល j ទៅឆ្វេង។ រាល់ជំហានដកជម្រើសមួយចោល → សរុបយ៉ាងច្រើន n ជំហាន។

✍️ លំហាត់ ២.២

រក Index នៃធាតុធំបំផុតក្នុង List គ្មានតម្រៀប — Big-O ល្អបំផុត?

មើលចម្លើយ

ត្រូវមើលគ្រប់ធាតុម្តង → O(n)។

✍️ លំហាត់ ២.៣

ហេតុអ្វីការបញ្ចូលធាតុនៅ ដើម Python list យឺត?

មើលចម្លើយ

ត្រូវរំកិលធាតុទាំងអស់មួយកន្លែង → O(n) (append នៅចុងជា O(1))។

✍️ លំហាត់ ២.៤

ពិនិត្យថា String «level» ជា Palindrome ដោយ Two pointers ពិពណ៌នាជំហាន។

មើលចម្លើយ

ចាប់ i = 0, j = ចុង → ប្រៀប s[i] និង s[j] → ខុស = មិនមែន → ត្រូវ: i+1, j−1 → ដល់ i ≥ j = Palindrome · O(n)។

មេរៀន ៦Recursion & Backtracking

Recursion = Function ហៅខ្លួនឯងលើបញ្ហាតូចជាង។ ត្រូវមាន Base case (ឈប់) និង Recursive case។ Backtracking = សាក → បើខុស ត្រឡប់ក្រោយ → សាកផ្លូវផ្សេង។

លទ្ធផលពិត · Python 3
5! = 120
['ABC', 'ACB', 'BAC', 'BCA', 'CAB', 'CBA']
ក្រដាសប្រាក់ (រៀល) ដែលបូកស្មើ 15000៖
  ✓ [10000, 5000]
  ✓ [10000, 2000, 1000, 2000]
⚠️ គ្មាន Base case = RecursionError (Python ដាក់ដែនកំណត់ ~1000 ជាន់)។

✍️ លំហាត់ ៦

Base case របស់ factorial ជាអ្វី? បើគ្មានវា កើតអ្វី?

មើលចម្លើយ

✍️ លំហាត់ ៦.២

មេរៀន ៩Tree & Binary Search Tree (BST)

Tree = Node មាន Root និងកូន (ដូចមែកធាង Folder)។ BST៖ កូនឆ្វេង < Node < កូនស្តាំ → ស្វែងរក O(log n) (បើមានតុល្យភាព)។ Inorder traversal ចេញលំដាប់តម្រៀប។

មើលចម្លើយ

BFS ពិនិត្យ ស្រទាប់ៗ (ចម្ងាយ 1 ទាំងអស់ → 2 → 3…) ដូច្នេះលើកដំបូងដែលដល់គោលដៅ គឺតាមផ្លូវខ្លីបំផុត។ DFS ដើរជ្រៅលើផ្លូវមួយមុន — អាចដល់គោលដៅតាមផ្លូវវែង។

មេរៀន ១៣Dynamic Programming (DP)

DP = បំបែកបញ្ហាជាបញ្ហារង ដែលកើតឡើងដដែលៗ ហើយ ចងចាំចម្លើយ (Memoization) — កាត់ពី Exponential មក Polynomial។ ពាក្យ «Dynamic programming» ដោយ Richard Bellman (1950s)។

លទ្ធផលពិត · Python 3
fib(27) គ្មាន Memo ≈ 17 ms · មាន Memo ≈ 0.008 ms
fib(200) = 280571172992510140037611932413038677189525
ក្រដាសប្រាក់តិចបំផុតសម្រាប់ 18,600៛ = 6

✍️ លំហាត់ ១៣

ពីរលក្ខណៈអ្វីដែលបញ្ជាក់ថាបញ្ហាអាចប្រើ DP?

មើលចម្លើយ

(1) Overlapping subproblems — បញ្ហារងដដែលគណនាច្រើនដង (2) Optimal substructure — ចម្លើយល្អបំផុតផ្សំពីចម្លើយល្អបំផុតនៃបញ្ហារង។

✍️ លំហាត់ ១៣.២

ចំនួនវិធីឡើងជណ្តើរ n កាំ (ម្តង 1 ឬ 2 កាំ) — រូបមន្ត DP?

មើលចម្លើយ

dp[n] = dp[n-1] + dp[n-2] · dp[1]=1, dp[2]=2 → n=5: 8 វិធី។

✍️ លំហាត់ ១៣.៣

Coin change (1, 3, 4) បង់ 6 កាក់តិចបំផុត — Greedy ឬ DP?

មើលចម្លើយ

Greedy: 4+1+1 = 3 កាក់ (ខុស) · DP: 3+3 = 2 កាក់។
