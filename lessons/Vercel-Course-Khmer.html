Git → Vercel Workflow

មេរៀន ១Deploy Website ស្តាទិកដំបូង (HTML)

ឧទាហរណ៍៖ ដាក់វគ្គរៀន HTML ទាំងអស់ដែលអ្នកមាន (NodeJS-Course-Khmer.html, SQL-Course-Khmer.html…) ជា Website តែមួយ។

វិធី ១: Vercel CLI

វិធី ២: GitHub (ណែនាំ)

  1. Push Folder ទៅ GitHub Repository
  2. Vercel Dashboard → Add New… → Project → Import Repository
  3. Framework Preset៖ Other · Build Command៖ ទទេ · Output Directory៖ . (Root)
  4. ចុច Deploy → រាល់ពេល git push ទៅ main = Deploy ថ្មីដោយស្វ័យប្រវត្តិ

cleanUrls៖ /SQL-Course-Khmer.html → /SQL-Course-Khmer (ស្អាតជាង)។

✍️ លំហាត់ ១

សរសេរ index.html សាមញ្ញ ដែលមាន Link ទៅវគ្គ ៣ ហើយពន្យល់ថាហេតុអ្វី Link គួរសរសេរ /SQL-Course-Khmer មិនមែន SQL-Course-Khmer.html ពេលបើក cleanUrls។

មើលចម្លើយ

ពេល cleanUrls: true Vercel Redirect .html → URL គ្មាន .html (308)។ Link ផ្ទាល់ទៅ URL ស្អាត ជៀសវាង Redirect មួយជុំ ហើយ URL ស្របគ្នា (ល្អសម្រាប់ SEO)។

មេរៀន ២Git Workflow: Preview & Production Deployments

  • Deployment ជា Immutable៖ URL នីមួយៗរក្សាកំណែនោះជារៀងរហូត (ដរាបណាមិនលុប)
  • Production Branch (Settings → Git)៖ ជាធម្មតា main
  • Ignored Build Step៖ រំលង Build ពេលប្តូរតែ Folder ដែលមិនពាក់ព័ន្ធ (Monorepo)
  • Deployment Protection៖ Preview តម្រូវឱ្យ Login Vercel (Vercel Authentication) — កុំឱ្យសាធារណៈឃើញ

✍️ លំហាត់ ២

ក្រុមអ្នកមាន ៣ Branch៖ main, develop, feature/cart។ ចង់ឱ្យ develop មាន URL ថេរ «staging» សម្រាប់អតិថិជនសាក។ ធ្វើដូចម្តេច?

មើលចម្លើយ

Project → Settings → Domains → Add staging.kafe.com (ឬ kafe-staging.vercel.app) → ជ្រើស Git Branch: develop។ រាល់ Push ទៅ develop → Domain staging បង្ហាញកំណែថ្មីបំផុត។ ដាក់ Environment variables «Preview» សម្រាប់ Branch develop (ឧ. Database staging)។

SPA + React Router: ការពារ 404 ពេល Refresh

React Router បង្កើតទំព័រ /products/5 ក្នុង Browser ប៉ុន្តែគ្មាន File នោះលើ Server។ ពេល Refresh → 404។ ដោះស្រាយដោយ Rewrite គ្រប់ Path ទៅ index.html៖

💡 Rewrite អនុវត្តតែពេល គ្មាន File ពិត ត្រូវនឹង Path ប៉ុណ្ណោះ — /assets/index-abc.js នៅតែបម្រើ File JS ធម្មតា។

✍️ លំហាត់ ៣

Build បរាជ័យលើ Vercel ជាមួយ «Error: Could not resolve "./components/Header"» ប៉ុន្តែដំណើរការក្នុង Windows ធម្មតា។ File ពិតឈ្មោះ header.jsx។ មូលហេតុ?

មើលចម្លើយ

Vercel Build លើ Linux ដែលបែងចែក អក្សរធំ/តូច (Case-sensitive)។ Windows/macOS មិនបែងចែក។ កែ៖ ប្តូរឈ្មោះ File ជា Header.jsx (ប្រើ git mv header.jsx Header.jsx ដើម្បីឱ្យ Git ដឹង) ឬកែ Import ឱ្យត្រូវ។ ទម្លាប់ល្អ៖ រត់ npm run build មុន Push។

មេរៀន ៥Vercel Functions: API ក្នុង Folder api/

File ក្នុង Folder api/ ក្លាយជា Endpoint ដោយស្វ័យប្រវត្តិ៖ api/hello.js → /api/hello។ Functions ប្រើ Web standard Request / Response។

  • Fluid compute (Default)៖ Instance មួយទទួល Request ច្រើនព្រមគ្នា, កាត់បន្ថយ Cold start, គិតប្រាក់តាម Active CPU
  • Stateless៖ កុំទុកទិន្នន័យក្នុង Variable/File ក្នុង Function — វាអាចបាត់ពេលណាក៏បាន → ប្រើ Database
  • Max duration (Hobby)៖ 300 វិនាទី · ភាសា៖ Node.js, Python, Go, Ruby, Bun…
