មេរៀន ៤Neon៖ បង្កើត PostgreSQL ឥតគិតថ្លៃ

🧩 ពន្យល់ជំហានៗ
  1. ចូល neon.com → Sign up (GitHub/Google)
  2. Create project → ឈ្មោះ kafe → Region ជិតអ្នកប្រើ (ឧ. Singapore ap-southeast-1)
  3. Dashboard → Connect → ចម្លង Connection string (ជ្រើស Pooled connection)
  4. SQL Editor → បិទភ្ជាប់ schema.sql → Run
  5. Tables → មើលទិន្នន័យ
💡 Pooled (មាន -pooler) ល្អសម្រាប់ App ដែលបើក Connection ច្រើន។ Branching៖ បង្កើតច្បាប់ចម្លង Database សម្រាប់សាក (ដូច Git branch)។ Free compute ដេកក្រោយ 5 នាទី — Query ដំបូងយឺតបន្តិច។

💡 3 ច្បាប់ដែល Hosting ទាមទារ៖ (1) Listen លើ process.env.PORT (2) មាន Script start (3) តម្លៃសម្ងាត់មកពី Environment variables។

✍️ លំហាត់ ៥

ហេតុអ្វី Backend ត្រូវប្រើ process.env.PORT មិនមែនលេខ 3000 ថេរ?

មើលចម្លើយ

ព្រោះ Railway/Render កំណត់ Port ដោយខ្លួនឯង ហើយផ្ញើតាម Env variable PORT។ បើ App Listen លើ Port ផ្សេង Platform រក App មិនឃើញ → Error 502/Application failed to respond។

មេរៀន ៦Deploy Backend លើ Railway (ជំហានៗ)

🧩 ពន្យល់ជំហានៗ
  1. ចូល railway.com → Login ដោយ GitHub
  2. New Project → Deploy from GitHub repo → ជ្រើស kafe
  3. ចុច Service → Settings → Root Directory = /server (Railway រកឃើញ Node ដោយស្វ័យប្រវត្តិ ហើយប្រើ npm start)
  4. Variables → បន្ថែម DATABASE_URL (ពី Neon) និង CORS_ORIGIN (URL Vercel — ដាក់ក្រោយក៏បាន)
  5. Settings → Networking → Generate Domain → បាន https://….up.railway.app
  6. បើក /api/health → {"ok":true} ✅ · មើល Deploy Logs បើមានបញ្ហា
  7. រាល់ពេល git push → Railway Deploy ថ្មីដោយស្វ័យប្រវត្តិ
💡 តម្លៃ (វិច្ឆិកា 2026)៖ Free = ឥណទាន $1/ខែ (0.5 GB RAM, 1 vCPU ក្នុងមួយ Service) · Trial = $5 ម្តង · Hobby = $5/ខែ (រួម $5 usage)។ API តូចសម្រាប់ Portfolio ប្រើតិច។ ពិនិត្យ Usage ក្នុង Dashboard។
