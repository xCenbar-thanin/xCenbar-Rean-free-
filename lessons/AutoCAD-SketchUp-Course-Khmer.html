មេរៀន ១CAD ជាអ្វី? · Technical drawing

CAD (Computer-Aided Design) = ការគូរ/រចនាដោយកុំព្យូទ័រ ជំនួសការគូរដៃលើក្រដាស — ត្រឹមត្រូវដល់ mm កែលឿន ចែករំលែកបាន និងបង្កើត 3D។

ប្រភេទគំនូរបង្ហាញ
Plan (ប្លង់)មើលពីលើ (កាត់ផ្តេកកម្ពស់ ~1.2m)
Elevation (ផ្នែកមុខ)មើលពីមុខ/ចំហៀង

គូរបាត់មិនឃើញអ្វីលើអេក្រង់ — ត្រូវវាយអ្វី?

មេរៀន ៣កូអរដោនេ · Absolute · Relative · Polar

ទម្រង់ឧទាហរណ៍ន័យ
Absolute3000,2000ពីចំណុច (0,0)
Relative@4000,0ពីចំណុចចុងក្រោយ ទៅស្តាំ 4000
Polar@3000<90ចម្ងាយ 3000 មុំ 90° (ឡើងលើ)
🧩 ពន្យល់ជំហានៗ
  1. វាយ L Enter
  2. ចំណុចដំបូង 0,0
  3. @4000,0 (ជញ្ជាំង 4m ទៅស្តាំ)
  4. @3000<90 (ឡើងលើ 3m)
  5. @-4000,0 (ត្រឡប់ឆ្វេង)
  6. C (Close) → បន្ទប់ 4×3m
💡 មុំក្នុង AutoCAD៖ 0° = ស្តាំ (East) · 90° = លើ · 180° = ឆ្វេង · 270° = ក្រោម (ច្រាសទ្រនិចនាឡិកា)។ សាកក្នុង CAD Lab!

✍️ លំហាត់ ៣

ពីចំណុច (1000,1000) វាយ @2000<180 ទៅដល់ណា?

មើលចម្លើយ

មុំ 180° = ទៅឆ្វេង 2000 → (−1000, 1000)។

🧩 ពន្យល់ជំហានៗ
  1. គូរ 1:1 (mm) ក្នុង Model space
  2. ចូល Layout → Page setup (A3, Plotter = DWG To PDF)
  3. បញ្ចូល Title block
