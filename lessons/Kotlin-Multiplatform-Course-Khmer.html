១. Kotlin Multiplatform (KMP) ជាអ្វី?

Kotlin Multiplatform (KMP) របស់ក្រុមហ៊ុន JetBrains អនុញ្ញាតឲ្យសរសេរ Logic តែម្តង (Business rules, API, Database, ViewModel) ជាភាសា Kotlin ហើយប្រើក្នុង Android, iOS, Desktop និង Web — ខណៈ UI អាចនៅជា Native (Jetpack Compose + SwiftUI) ឬចែករំលែកដោយ Compose Multiplatform។ ខុសពី Flutter/React Native៖ KMP Compile ទៅ Native ពិត (JVM bytecode លើ Android · Native binary/Framework លើ iOS)។

🧩 របៀប Code ជំហានៗ

  2. data class Money(val cents: Long) — រក្សាលុយជា សេន (integer) ជៀសកំហុស Floating point · operator fun plus/times ឲ្យសរសេរ a + b, price * qty។
  3. sealed interface Coupon + when — Compiler បង្ខំឲ្យដោះស្រាយគ្រប់ប្រភេទ Coupon។
  4. commonMain គ្មាន API ពិសេសរបស់ JVM (ឧ. String.format) → format() សរសេរដោយ padStart/chunked។

  6. លទ្ធផលពិតខាងលើ Compile ដោយ Kotlin 2.0.21 — Code ដដែលនេះ Kotlin/Native Compile ទៅ iOS Framework។
