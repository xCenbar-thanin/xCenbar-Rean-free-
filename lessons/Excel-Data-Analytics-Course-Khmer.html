១. Excel វិភាគទិន្នន័យ — អ្នកណាបង្កើត?

Data analysis = ការប្រមូល សម្អាត រៀបចំ និងបកស្រាយទិន្នន័យ ដើម្បីជួយ សម្រេចចិត្ត។ Excel ជាឧបករណ៍វិភាគដែលប្រើច្រើនបំផុតលើពិភពលោក — វគ្គនេះនាំអ្នកពី Clean data → Lookup → PivotTable → Power Query → Dashboard ដោយរូបមន្ត Excel (គ្មាន Programming)។

មេរៀន ៤Lookup — XLOOKUP · INDEX/MATCH

✍️ លំហាត់ ៤

ខ្វះ FALSE (Exact match) — Default ជា Approximate match។

មេរៀន ៦Dynamic arrays — FILTER · SORT · UNIQUE

🧩 ពន្យល់ជំហានៗ
  1. រូបមន្ត ១ ក្រឡា «ហៀរ» (Spill) លទ្ធផលច្រើនក្រឡា — #SPILL! = មានទិន្នន័យរារាំង។
  2. LET ដាក់ឈ្មោះអថេរក្នុងរូបមន្ត · LAMBDA បង្កើតអនុគមន៍ផ្ទាល់ខ្លួន។
