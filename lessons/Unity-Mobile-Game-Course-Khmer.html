មេរៀន ២Game Loop & Time.deltaTime

🧩 របៀប Code ជំហានៗ
  1. Game loop៖ Engine ហៅ Update() រាល់ Frame — 60 FPS = 60 ដង/វិនាទី។
  2. Time.deltaTime = ពេលវេលា (វិនាទី) ចាប់ពី Frame មុន · គុណល្បឿននឹង deltaTime → ល្បឿន ក្នុងមួយវិនាទី មិនមែនក្នុងមួយ Frame។
  3. Demo៖ បន្ថយ FPS ទៅ 15 → ប្រអប់ក្រហម (គ្មាន deltaTime) យឺត ៤ ដង តែប្រអប់ខៀវនៅល្បឿនដដែល ✅។
  4. FixedUpdate() — ចន្លោះថេរ សម្រាប់ Physics (Rigidbody) · Update() សម្រាប់ Input និងចលនាមិនមែន Physics។
  5. Awake → Start → (FixedUpdate/Update/LateUpdate)… → OnDestroy (រូបភាពខាងលើ)។

✍️ លំហាត់ ២

ទូរស័ព្ទមួយរត់ 30 FPS មួយទៀត 120 FPS។ Code x += 0.1f ក្នុង Update ធ្វើឲ្យខុសគ្នាប៉ុន្មានដង?

មើលចម្លើយ

៤ ដង (120 / 30) — ទូរស័ព្ទខ្លាំងរត់លឿនជាង។ ត្រូវ x += speed * Time.deltaTime។

មេរៀន ៣Vector & ចលនា (Movement)

🧩 របៀប Code ជំហានៗ
  1. Vector2(x, y) = ទិស + ទំហំ · Vector2.right/up = (1,0)/(0,1)។
  2. ចុច → និង ↑ ព្រមគ្នា = (1,1) មានប្រវែង √2 ≈ 1.41 → ដើរទ្រេតលឿនជាង · Normalize/ClampMagnitude ធ្វើឲ្យប្រវែង ≤ 1 (បិទ/បើក normalized ក្នុង Demo ហើយមើល speed ×)។
  3. Mathf.Clamp — កុំឲ្យចេញក្រៅអេក្រង់ · Mathf.Atan2 — រកមុំពីទិស (គណិតពីវគ្គ Math for IT)។
  4. Virtual joystick៖ ចម្ងាយពីចំណុចចុច → ទិស (Demo៖ អូសលើ Canvas)។

មេរៀន ៤Physics 2D៖ Rigidbody, Gravity & Jump

🧩 របៀប Code ជំហានៗ
  1. Rigidbody2D — Unity គណនា Gravity, ល្បឿន, ការប៉ះ ឲ្យស្វ័យប្រវត្តិ (Inspector៖ Gravity Scale, Mass, Freeze Rotation)។
  2. Physics = v += g·dt ហើយ y += v·dt រៀងរាល់ FixedUpdate (0.02s) — Demo ធ្វើតាមដូចគ្នា។
  3. AddForce(..., ForceMode2D.Impulse) — រុញភ្លាមៗ (លោត) · Reset velocity.y មុន ដើម្បីលោតស្មើគ្នា។
  4. Ground check៖ Physics2D.OverlapCircle លើ Layer "Ground" → កុំឲ្យលោតលើអាកាស។
  5. Input អានក្នុង Update · ប្រើ Physics ក្នុង FixedUpdate (Queue jumpQueued)។ សាកប្តូរ gravity/jumpForce ក្នុង Demo!

មេរៀន ៧Prefab, Spawning & Object Pooling

🧩 របៀប Code ជំហានៗ

  4. Demo៖ បើក Pool → created ឈប់កើននៅប្រហែល 12–15 · បិទ Pool → created/destroyed កើនរហូត (ការងារ GC ច្រើន)។
