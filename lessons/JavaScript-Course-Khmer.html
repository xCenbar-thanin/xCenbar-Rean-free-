១. JavaScript ជាអ្វី? អ្នកណាបង្កើត? ប្រើធ្វើអ្វី?

JavaScript (JS) ជាភាសាសរសេរកម្មវិធីដែលធ្វើឲ្យគេហទំព័រ មានជីវិត និងអន្តរកម្ម។ ប្រៀបធៀប៖ HTML = គ្រោងឆ្អឹង, CSS = សម្លៀកបំពាក់, JavaScript = ខួរក្បាល និងចលនា។

👤 អ្នកបង្កើត

Brendan Eich បានបង្កើត JavaScript ក្នុងឆ្នាំ 1995 នៅក្រុមហ៊ុន Netscape ដោយប្រើពេលប្រហែល ១០ ថ្ងៃ។ ឈ្មោះដើមគឺ Mocha → LiveScript → JavaScript។ ស្តង់ដារផ្លូវការហៅថា ECMAScript (ES6/ES2015 ជាកំណែធំបំផុតដែលបន្ថែម let, const, =>, class…)។

⚠️ JavaScript មិនមែនជា Java ទេ! ជាភាសាពីរផ្សេងគ្នាទាំងស្រុង ឈ្មោះគ្រាន់តែស្រដៀងគ្នាដោយសារការទីផ្សារនៅសម័យនោះ។

🎯 គេប្រើ JavaScript ដើម្បីធ្វើអ្វី?

  • ធ្វើឲ្យ web មានអន្តរកម្ម៖ ប៊ូតុង, ម៉ឺនុយ, slider, popup, form validation
  • ផ្លាស់ប្តូរ HTML/CSS ភ្លាមៗដោយមិនបាច់ផ្ទុកទំព័រថ្មី (DOM)
  • ទាញទិន្នន័យពី server (API) ដូចជា ផ្ទាំងអាកាសធាតុ, news
  • សរសេរ Web App (React, Vue, Angular), Mobile App (React Native), Desktop App (Electron)
  • សរសេរ Server/Backend ដោយ Node.js
  • ហ្គេមក្នុង browser, ការគូរក្រាហ្វ (Canvas, Chart.js)

🛠️ ត្រៀម និងភ្ជាប់ JavaScript

មិនចាំបាច់ install អ្វីទេ — browser មាន JavaScript ស្រាប់។ ប្រើ VS Code + Live Server (មើល ផ្នែកដំឡើង)។ ចុច F12 → tab Console ដើម្បីមើលលទ្ធផលពី console.log()។ ភ្ជាប់ JS បាន ៣ វិធី៖

💡 defer ប្រាប់ browser ឲ្យរង់ចាំ HTML ផ្ទុកចប់សិន ទើបរត់ JS — ជៀសវាងកំហុស "element not found"។

ពីមេរៀនទី ១ ដល់ ៨ ខ្ញុំប្រើផ្នែក Console បង្ហាញលទ្ធផលក្រោម code ផ្ទាល់ (អ្នកអាច copy ទៅសាកល្បងក្នុង VS Code ដែរ)។
