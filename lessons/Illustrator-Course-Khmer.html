១. Illustrator ជាអ្វី? អ្នកណាបង្កើត?

Adobe Illustrator គឺជាកម្មវិធីរចនា Vector graphics — រូបភាពដែលបង្កើតពី Path គណិតវិទ្យា (មិនមែន Pixel) ដូច្នេះពង្រីកប៉ុន្មានក៏ច្បាស់។ គេប្រើវាសម្រាប់ Logo, Icon, Name card, Brochure, Poster, Packaging, Illustration, Infographic និងអក្សររចនា។

ពាក្យន័យ

🧩 របៀប Code ជំហានៗ
  1. M x y = Move (Anchor ដំបូង) · L x y = Line ត្រង់ទៅ Anchor បន្ទាប់។
  2. Z = បិទ Path (ត្រឡប់ទៅចំណុចដំបូង) → មាន Fill បាន។
  3. Q cx cy x y = ខ្សែកោងមាន Handle មួយ · C = មាន Handle ពីរ (ដូច Pen tool)។
  4. fill = ពណ៌ខាងក្នុង · stroke = ស៊ុម · stroke-width = កម្រាស់។
