១. Software Testing ជាអ្វី? អ្នកណាបង្កើត?

Automated testing = កូដដែលពិនិត្យកូដរបស់អ្នកដោយស្វ័យប្រវត្តិ។ ជំនួសឱ្យការចុចសាកដោយដៃរាល់ពេលកែកូដ Tests រត់ក្នុងប៉ុន្មានវិនាទី ហើយប្រាប់ភ្លាមថាអ្វីខូច — មុនអ្នកប្រើឃើញ។

Testing Pyramid (ពីរ៉ាមីត)

២. របៀបដំឡើងក្នុង VS Code

  1. Node.js LTS (22+) — មាន Test runner ស្រាប់ (node --test) មិនចាំបាច់ដំឡើងអ្វី
  2. Vitest (គម្រោង Vite/React)៖ npm i -D vitest
  3. Playwright៖ npm init playwright@latest (ដំឡើង Browsers + Config + Example)
  4. VS Code Extensions៖ Vitest (ផ្លូវការ) — ▶ រត់ Test ម្តងមួយពីក្នុង Editor · Playwright Test for VS Code (Microsoft) — Record, Pick locator, Debug
  5. VS Code មាន Testing panel (រូបដបពិសោធន៍ 🧪) បង្ហាញ Tests ទាំងអស់

គម្រោងគំរូ kafe/ (ប្រើក្នុងមេរៀនទាំងអស់)

៣. ធាតុនីមួយៗរបស់ Testing

ធាតុពន្យល់

Test / Suitetest()/it() = ករណីមួយ · describe() = ក្រុម

Coverage% បន្ទាត់/Branch ដែល Tests បានរត់កាត់

Test អ្វី? (យុទ្ធសាស្ត្រ)

  • Unit៖ Logic អាជីវកម្ម (តម្លៃ, បញ្ចុះ, ពិន្ទុ, Validation) — ច្រើនបំផុត
  • Integration៖ API Routes + DB, Components + Hooks + Network (MSW)
  • E2E៖ ផ្លូវសំខាន់ៗ (Critical paths) — Login, Checkout, Payment — ៥–២០ Tests
  • Bug ថ្មីនីមួយៗ → សរសេរ Test ដែលបង្ហាញ Bug មុន បន្ទាប់មកជួសជុល (Regression test)
  • កុំ Test Library ខាងក្រៅ ឬលម្អិតខាងក្នុង (Private state) — Test អាកប្បកិរិយា
