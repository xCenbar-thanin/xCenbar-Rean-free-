១. Docker និង CI/CD ជាអ្វី? អ្នកណាបង្កើត?

Docker វេចខ្ចប់ App + Node.js + Library + ការកំណត់ ទៅក្នុង Image តែមួយ។ ពេលរត់ Image វាក្លាយជា Container — ដំណើរការដាច់ដោយឡែក ស្រាលជាង Virtual Machine ច្រើន ព្រោះប្រើ Kernel រួមជាមួយ Host។ លែងមានពាក្យ «វាដើរលើម៉ាស៊ីនខ្ញុំ តែមិនដើរលើ Server»។

CI/CD = Continuous Integration (រាល់ Push → Build + Test ស្វ័យប្រវត្តិ) និង Continuous Delivery/Deployment (កូដដែលជាប់ Test → Deploy ស្វ័យប្រវត្តិ)។

Registryឃ្លាំងរក្សា Images (Docker Hub, GitHub Container Registry, AWS ECR)
Volumeទិន្នន័យដែលនៅរស់ ទោះលុប Container (Database files)
NetworkContainers ក្នុង Network ដូចគ្នា ហៅគ្នាតាមឈ្មោះ (DNS)
