២. របៀបដំឡើង PowerPoint (និងភ្ជាប់ជាមួយ VS Code)

⚠️ PowerPoint មិនដំឡើងក្នុង VS Code ទេ។ វាជាកម្មវិធីក្នុង Microsoft 365។ VS Code ប្រើតែពេលអ្នក សរសេរកូដ បង្កើត Add-in ឬបង្កើត Slide ដោយស្វ័យប្រវត្តិ (Python / JavaScript)។

ជំហានទី ១: ដំឡើង PowerPoint

  1. ឥតគិតថ្លៃ៖ ចូល office.com → Sign in → PowerPoint for the web
  2. ពេញលេញ៖ Microsoft 365 (ឬគណនីសាលា) → office.com → Install apps → ដំឡើង → Sign in
  3. ទូរស័ព្ទ៖ Microsoft PowerPoint ឬ Microsoft 365 Copilot app
  4. អក្សរខ្មែរ៖ ប្រើ Font Unicode ដូចជា Khmer OS Battambang, Kantumruy Pro, Noto Sans Khmer · ពេលផ្ញើ File ទៅកុំព្យូទ័រផ្សេង៖ File → Options → Save → ធីក Embed fonts in the file
  5. បើក Developer tab៖ File → Options → Customize Ribbon → ធីក Developer (សម្រាប់ VBA)

ជំហានទី ២ (ជម្រើសសម្រាប់អ្នកសរសេរកូដ): VS Code

  1. ដំឡើង VS Code + Node.js LTS
  2. Extensions → Office Add-ins Development Kit → Create a new Add-in → ជ្រើស PowerPoint
  3. ឬប្រើ Python៖ pip install python-pptx ដើម្បីបង្កើត Slide ពីទិន្នន័យ

មេរៀន ១Slide ដំបូង: Layout, Placeholder, Views

  1. File → New → Blank Presentation (ឬជ្រើស Template)
  2. Home → New Slide (Ctrl+M) → ជ្រើស Layout
  3. ចុចក្នុង Placeholder ហើយវាយ · ប្តូរ Layout៖ Home → Layout
  4. ផ្លាស់ទីលំដាប់៖ អូស Thumbnail ឬប្រើ Slide Sorter · Section (ចុចស្តាំ → Add Section) ដើម្បីបែងចែកជំពូក
  5. រក្សាទុក Ctrl+S → .pptx

✍️ លំហាត់ ១

បង្កើត Presentation ៥ Slide «ខ្លួនខ្ញុំ»៖ Title, អំពីខ្ញុំ, ចំណូលចិត្ត, គោលដៅ, សូមអរគុណ។ តើគួរប្រើ Layout អ្វីសម្រាប់ Slide នីមួយៗ?

មើលចម្លើយ
  1. Title Slide — ឈ្មោះ + ចំណងជើងរង
  2. Two Content — រូបថតខាងឆ្វេង ព័ត៌មានខាងស្តាំ
  3. Title Only + Icons ៣–៤ (Insert → Icons)
  4. Title and Content — ៣ ចំណុចខ្លីៗ
  5. Section Header ឬ Blank + អក្សរធំ «សូមអរគុណ»

មេរៀន ២អក្សរ: ច្បាប់ ១ គំនិត ក្នុង ១ Slide

  • Assertion-Evidence៖ ចំណងជើង = ប្រយោគសារ (ឧ. «ចំណូលកើន 18% ដោយសារ Latte») + រូប/ក្រាហ្វជាភស្តុតាង
  • ជៀសវាង Bullet ច្រើនពេក — អ្នកស្តាប់អាន មិនស្តាប់។ ប្រើ ប្រហែល ៦ ពាក្យ × ៦ បន្ទាត់ ជាអតិបរមា
  • ទំហំអក្សរ៖ ចំណងជើង 32–44pt · អត្ថបទ ≥ 20–24pt (Guy Kawasaki៖ ≥ 30pt)
  • Font ២ ប្រភេទប៉ុណ្ណោះ · អក្សរខ្មែរ Line spacing 1.1–1.3

✍️ លំហាត់ ២

សរសេរ Slide ខាងក្រោមឡើងវិញតាម Assertion-Evidence៖ ចំណងជើង «ការស្ទង់មតិ» ជាមួយ Bullet ៖ «សិស្ស 200 នាក់ត្រូវបានសួរ / 72% ចូលចិត្តរៀនអនឡាញ / 28% ចូលចិត្តរៀនក្នុងថ្នាក់»។

មើលចម្លើយ

ចំណងជើង៖ «សិស្ស ៣ ក្នុង ៤ នាក់ ចូលចិត្តរៀនអនឡាញ»
ភស្តុតាង៖ Doughnut chart 72% / 28% (ពណ៌ Accent តែលើ 72%) + អក្សរតូចខាងក្រោម «ស្ទង់មតិសិស្ស 200 នាក់, មីនា 2026»។ ដក Bullet ទាំងអស់ចេញ — និយាយវាដោយមាត់។

មេរៀន ៤រូបភាព, Icons, Shapes & Merge Shapes

  • Insert → Pictures (Stock Images ឥតគិតថ្លៃក្នុង Microsoft 365) · Icons · 3D Models
  • Picture Format → Crop to Shape (រូបរង្វង់), Aspect Ratio 16:9, Remove Background
  • Shape Format → Merge Shapes៖ Union, Combine, Fragment, Intersect, Subtract — បង្កើត Icon/Logo ផ្ទាល់ខ្លួន
  • Transparency លើ Shape ខ្មៅ 40% ដាក់លើរូប → អក្សរសអានច្បាស់
  • Compress Pictures (Picture Format) ដើម្បីបន្ថយទំហំ File
  • ប្រើតែរូបដែលមានសិទ្ធិ៖ Stock Images, Unsplash, Pexels ឬរូបផ្ទាល់ខ្លួន

មេរៀន ៦Slide Master & Template

Slide Master = «Design System» របស់ PowerPoint។ ប្តូរម្តង → គ្រប់ Slide ប្តូរតាម។
