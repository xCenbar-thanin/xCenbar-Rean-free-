មេរៀន ៣VPS ពីសូន្យ៖ Ubuntu · Nginx · Node · HTTPS

🧩 ពន្យល់ជំហានៗ
  1. បង្កើត Droplet/VPS → Ubuntu LTS → ជ្រើស SSH key (មិនមែន Password)
  2. ចូល ssh root@IP → បង្កើត User ថ្មី + បិទ root login
  3. Firewall (ufw)៖ អនុញ្ញាតតែ SSH, 80, 443
  4. ដំឡើង Node + PM2 → ដំណើរការ App
  5. Nginx ជា Reverse proxy → Domain
  6. Certbot → HTTPS ឥតគិតថ្លៃ (បន្តស្វ័យប្រវត្តិ)
⚠️ VPS = អ្នកទទួលខុសត្រូវសុវត្ថិភាពទាំងស្រុង៖ Update ប្រព័ន្ធជាប្រចាំ · SSH key · Firewall · Backup។ បើមិនទាន់ចេះ Linux សូមរៀនវគ្គ Linux & Command Line មុន ឬប្រើ PaaS។
