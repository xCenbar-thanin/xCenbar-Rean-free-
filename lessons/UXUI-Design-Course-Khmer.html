១. UX/UI Design ជាអ្វី?

UX = User Experience
បទពិសោធន៍អ្នកប្រើ — តើ App ងាយប្រើ មានប្រយោជន៍ ហើយដោះស្រាយបញ្ហាពិតឬទេ? (Research, Flow, Wireframe, Testing)
UI = User Interface
ផ្ទៃប្រើប្រាស់ — អ្វីដែលអ្នកប្រើ មើលឃើញ និងចុច៖ ពណ៌ អក្សរ ប៊ូតុង Icon ប្លង់ ចលនា
💡 ឧទាហរណ៍ងាយ៖ ផ្ទះមួយ — UX គឺការរៀបចំបន្ទប់ឱ្យរស់នៅស្រួល (ផ្លូវដើរ, ទីតាំងបង្គន់, ពន្លឺ) ហើយ UI គឺពណ៌ជញ្ជាំង, គ្រឿងសង្ហារិម, កុងតាក់ភ្លើង។ ផ្ទះស្អាតតែរស់នៅលំបាក = UI ល្អ UX អាក្រក់។

Success rate = 3 ÷ 5 = 60% · ពេលមធ្យម = (40 + 55 + 70) ÷ 3 = 55 វិនាទី។
