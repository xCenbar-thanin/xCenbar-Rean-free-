១. Trading ជាអ្វី? អ្នកណាបង្កើត?

⚠️ ការព្រមាន (សូមអានមុនរៀន)៖ វគ្គនេះសម្រាប់ ការអប់រំប៉ុណ្ណោះ មិនមែនជាដំបូន្មានហិរញ្ញវត្ថុ ឬការណែនាំឲ្យទិញ/លក់ទេ។ Trading មាន ហានិភ័យខ្ពស់ — អ្នកអាចបាត់បង់ប្រាក់ទាំងអស់ (ជាពិសេសពេលប្រើ Leverage)។ Broker CFD ដែលមានអាជ្ញាប័ណ្ណនៅអឺរ៉ុប ត្រូវបង្ហាញថាគណនីអតិថិជនភាគច្រើន (ជាទូទៅ ៧០–៨០%+) ខាតប្រាក់។
✅ អាយុក្រោម ១៨ ឆ្នាំ៖ រៀនទ្រឹស្តី និងហាត់តែលើ គណនីសាកល្បង (Demo) / Paper trading ក្នុងវគ្គនេះ ហើយពិភាក្សាជាមួយឪពុកម្តាយ។ ✅ កុំប្រើប្រាក់ខ្ចី ប្រាក់សាលា ឬប្រាក់ដែលអ្នកមិនអាចបាត់បង់បាន។ ✅ ប្រុងប្រយ័ត្ន ការបោកប្រាស់៖ «ចំណេញធានា ១០%/ខែ», «Signal VIP», «ផ្ញើលុយមកខ្ញុំ Trade ជំនួស» = សញ្ញាគ្រោះថ្នាក់។

Trading (ការជួញដូរ) = ការ ទិញ និងលក់ ទ្រព្យហិរញ្ញវត្ថុ (ភាគហ៊ុន រូបិយប័ណ្ណ Crypto…) ក្នុងរយៈពេលខ្លី ឬមធ្យម ដើម្បីរកចំណេញពីការ ប្រែប្រួលតម្លៃ។ Trader ល្អមិនមែនជាអ្នក «ទាយត្រូវ» គ្រប់ពេលទេ — តែជាអ្នកមាន ផែនការ, គ្រប់គ្រងហានិភ័យ និង វិន័យ។

មេរៀន ៧Bid/Ask · Spread · ថ្លៃសេវា · Slippage

Bid = តម្លៃដែលគេព្រមទិញពីអ្នក (អ្នកលក់នៅតម្លៃនេះ) · Ask = តម្លៃដែលគេព្រមលក់ឲ្យអ្នក (អ្នកទិញនៅតម្លៃនេះ)។ ទិញហើយលក់ភ្លាម = ខាត Spread។

📊 ឧទាហរណ៍គណនា (លទ្ធផល)
ថ្លៃក្នុង 1 Trade: $0.50
ថ្លៃសរុប 1 ឆ្នាំ: $1,250  (Trade 2,500 ដង)
Win rate 50%: Expectancy/Trade មុនថ្លៃ $+0.00 → ក្រោយថ្លៃ $-0.50
Win rate 52%: Expectancy/Trade មុនថ្លៃ $+0.40 → ក្រោយថ្លៃ $-0.10
Win rate 55%: Expectancy/Trade មុនថ្លៃ $+1.00 → ក្រោយថ្លៃ $+0.50
🧩 ពន្យល់ជំហានៗ
  1. Trade ញឹកញាប់ (Scalping) = ថ្លៃច្រើន → ត្រូវការ Edge ធំជាង។
  2. Win rate 50% (ឈ្នះ/ខាតស្មើ) = ខាត ពេលគិតថ្លៃ។
  3. Slippage៖ ពេលមានព័ត៌មានធំ (ឧ. NFP, ការប្រកាសការប្រាក់) Spread ពង្រីក ហើយ Order អាចបំពេញខុសតម្លៃ។
  4. Swap/Funding៖ ថ្លៃរក្សា Position ឆ្លងយប់ (Forex) ឬ Funding rate (Crypto Perpetual)។

  3. ហានិភ័យពិសេស៖ ព័ត៌មានភ្លាមៗ (ការវាយប្រហារនាវាប្រេង) · ថ្ងៃផុតកំណត់ · Gap។
  4. ខែមេសា ២០២០ កិច្ចសន្យា WTI មួយធ្លាក់ ក្រោមសូន្យ មួយរយៈខ្លី ព្រោះគ្មានកន្លែងស្តុក — រឿង «មិនអាចទៅរួច» អាចកើតឡើង!

✍️ លំហាត់ ១៤

ហេតុអ្វីកសិករដាំស្រូវ មាន «ហានិភ័យទំនិញ» ទោះមិនដែល Trade?

មើលចម្លើយ

ព្រោះចំណូលរបស់គាត់អាស្រ័យលើ តម្លៃអង្ករ — តម្លៃធ្លាក់ = ចំណូលធ្លាក់។ Futures/កិច្ចសន្យាទិញទុកមុន អាចជួយការពារ។

មេរៀន ១៥Indices៖ S&P 500 · Nasdaq · Nikkei · CSX Index

សន្ទស្សន៍ផ្សារហ៊ុន (Index) = លេខមួយ ដែលវាស់តម្លៃភាគហ៊ុនរបស់ក្រុមហ៊ុនមួយក្រុម។ ជំនួសការតាមដាន ៥០០ ក្រុមហ៊ុន យើងមើល Index មួយ។

  2. ប្រែប្រួលដោយ៖ ប្រាក់ចំណេញក្រុមហ៊ុន · អត្រាការប្រាក់ · ទិន្នន័យសេដ្ឋកិច្ច · អារម្មណ៍ទីផ្សារ។
  3. វិធី ២៖ Index fund / ETF រយៈពេលវែង (ថ្លៃទាប) ធៀបនឹង Index CFD/Futures រយៈពេលខ្លី (Leverage ហានិភ័យខ្ពស់)។
  4. 7%/ឆ្នាំ ជាឧទាហរណ៍ប៉ុណ្ណោះ — Index អាចធ្លាក់ 30–50% (ឧ. 2008) មុនឡើងវិញ។

មើលចម្លើយ

5,000 × 3% = 150 ពិន្ទុ × $2 = −$300។

មេរៀន ១៦CFDs៖ Trade ដោយមិនកាន់កាប់ទ្រព្យ · Margin · Swap

CFD (Contract for Difference) = កិច្ចសន្យារវាងអ្នក និង Broker ដើម្បីប្តូរ ភាពខុសគ្នានៃតម្លៃ របស់ទ្រព្យ (Forex មាស ប្រេង Index ភាគហ៊ុន) រវាងពេលបើក និងបិទ — អ្នក មិនដែលជាម្ចាស់ ទ្រព្យពិត។ អាច Long (ទិញ) ឬ Short (លក់)។

ពាក្យន័យ
Marginប្រាក់តម្កល់ដើម្បីបើក Position (ឧ. 1:100 → $100 គ្រប់គ្រង $10,000)
Margin callគណនីធ្លាក់ក្រោមកម្រិត → Broker ព្រមាន
Stop-outBroker បិទ Trade ដោយស្វ័យប្រវត្តិ

Swap 30 យប់ × $1.50 = $45.00 (ថ្លៃលាក់)
🧩 ពន្យល់ជំហានៗ
  1. ចំណេញ/ខាត = (តម្លៃបិទ − តម្លៃបើក) × ទំហំ (Short = ផ្ទុយ)។
  2. Leverage 1:100 → ប្រែប្រួលផ្ទុយតែ 1% = បាត់ Margin ទាំងអស់។
  3. នៅអឺរ៉ុប Broker ត្រូវប្រកាស — ប្រហែល 60–80% នៃគណនីអតិថិជនរាយ ខាតលុយ · CFD រាយ ហាមឃាត់ នៅអាមេរិក។
  4. នៅកម្ពុជា ពិនិត្យអាជ្ញាប័ណ្ណ Broker លើគេហទំព័រផ្លូវការ SERC · សាកដកប្រាក់តិចៗមុន · ហាត់ Demo ≥ ៣ ខែ។
