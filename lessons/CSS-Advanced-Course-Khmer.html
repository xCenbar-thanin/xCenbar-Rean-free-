១. CSS ជាអ្វី? អ្នកណាបង្កើត?

CSS (Cascading Style Sheets) គឺជាភាសាសម្រាប់ រចនា គេហទំព័រ៖ ពណ៌ អក្សរ គម្លាត ប្លង់ ចលនា និងការបត់បែនតាមអេក្រង់។ HTML = គ្រោងឆ្អឹង, CSS = សម្លៀកបំពាក់ និងការតុបតែង, JavaScript = ចលនា និងខួរក្បាល។

គេប្រើ CSS ធ្វើអ្វី?

  • រចនាគេហទំព័រ Web App និង Email ឱ្យស្អាត និងមានអត្តសញ្ញាណម៉ាក (Brand)
  • ប្លង់ Responsive លើទូរស័ព្ទ Tablet កុំព្យូទ័រ (Flexbox, Grid, Media/Container Queries)
  • Animation និង Transition ដោយមិនចាំបាច់ JavaScript
  • Dark mode, Theme, Design System សម្រាប់ក្រុមធំ
  • ទម្រង់បោះពុម្ព (Print), PDF, និង UI ក្នុង App (Electron, React Native Web)

@layer — កំណត់អាទិភាពជាស្រទាប់

Layer ក្រោយ ឈ្នះ layer មុន ទោះ specificity ទាបជាងក៏ដោយ។ ល្អសម្រាប់ដាក់ reset, framework និង style ខ្លួនឯងឲ្យមានលំដាប់ច្បាស់។

⚠️ style ដែលមិនស្ថិតក្នុង layer ណាមួយ ឈ្នះ style ក្នុង layer ទាំងអស់ (ក្រៅពី !important)។ ចំពោះ !important លំដាប់ត្រូវ បញ្ច្រាស៖ !important ក្នុង layer មុន (ឧ. base) ឈ្នះ layer ក្រោយ។

♿ Accessibility (a11y)

  • Contrast៖ អក្សរធៀបផ្ទៃ ≥ 4.5:1 (WCAG AA) — ពិនិត្យដោយ DevTools

  • គោរពអ្នកមិនចូលចិត្តចលនា៖ prefers-reduced-motion
  • ប៊ូតុង/តំណ ទំហំចុចយ៉ាងតិច 44×44px លើទូរស័ព្ទ
  • កុំប្រើតែពណ៌ដើម្បីបង្ហាញព័ត៌មាន (ជនពិការភ្នែកពណ៌)
