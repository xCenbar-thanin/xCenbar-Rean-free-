១. Power BI ជាអ្វី? អ្នកណាបង្កើត?

Power BI (Microsoft) ជាឧបករណ៍ Business Intelligence សម្រាប់ភ្ជាប់ទិន្នន័យច្រើនប្រភព សម្អាត (Power Query) បង្កើត Data model គណនា DAX measures ហើយបង្កើត Dashboard អន្តរកម្ម ចែករំលែកលើ Web/ទូរស័ព្ទ។ វគ្គនេះមានរូបមន្ត DAX និងលទ្ធផលគណនាឧទាហរណ៍ (គ្មាន Python)។

ឆ្នាំអ្នកបង្កើត / ព្រឹត្តិការណ៍សារៈសំខាន់
2009–2010Microsoft SQL Server team (Amir Netz និងក្រុម)PowerPivot · ភាសា DAX · VertiPaq engine
2010–2013Project Crescent → Power View · Power BI for Office 365Visualization លើ Web
2015 (កក្កដា)Power BI Desktopឥតគិតថ្លៃ — ប្រើទូទាំងពិភពលោក
2023Microsoft Fabricវេទិកាទិន្នន័យរួម (OneLake) ដែល Power BI ជាផ្នែកមួយ

មេរៀន ៣Data modeling — Star schema

🧩 ពន្យល់ជំហានៗ
  1. Fact = ប្រតិបត្តិការ (Units, Revenue) · Dimension = អ្នកណា/អ្វី/ពេលណា/ឯណា។

Total Revenue = $32,038.00
Total Units   = 15,473

🧩 ពន្យល់ជំហានៗ
