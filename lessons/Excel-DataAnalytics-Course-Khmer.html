⚠️ Excel មិនដំឡើងក្នុង VS Code ទេ — Excel ជាកម្មវិធីដាច់ដោយឡែករបស់ Microsoft។ VS Code ប្រើសម្រាប់ អ្នកសរសេរកូដ ដែលចង់៖ បង្កើត Office Add-in, វិភាគ File Excel ដោយ Python, ឬមើល CSV។ អ្នកប្រើធម្មតាគ្រាន់តែដំឡើង Excel។

ជំហានទី ១: ដំឡើង Excel

  1. ឥតគិតថ្លៃ៖ ចូល office.com → Sign in ដោយគណនី Microsoft → ប្រើ Excel for the web ក្នុង Browser
  2. ពេញលេញ៖ ទិញ/ជាវ Microsoft 365 (Personal/Family/Business) ឬប្រើគណនីសាលា (សិស្សជាច្រើនបានឥតគិតថ្លៃ) → ចូល office.com → Install apps
  3. បើក File ដំឡើង → រង់ចាំ → បើក Excel → Sign in ដើម្បីបើកដំណើរការ (Activate)
  4. ទូរស័ព្ទ៖ ទាញ Microsoft Excel ឬ Microsoft 365 Copilot app ពី Play Store / App Store
  5. បើក Developer tab៖ File → Options → Customize Ribbon → ធីក Developer (សម្រាប់ Macro/VBA)

ជំហានទី ២ (ជម្រើសសម្រាប់អ្នកសរសេរកូដ): VS Code

  3. សម្រាប់ Data Analytics៖ ដំឡើង Extension Python + Jupyter + Data Wrangler → អាន File .xlsx ដោយ pandas
  4. មើល CSV ជាតារាង៖ Extension Rainbow CSV ឬ Excel Viewer

មេរៀន ១២Data Analytics ជាអ្វី? ដំណើរការ ៦ ជំហាន

Data Analytics = ការប្រមូល សម្អាត វិភាគ និងបង្ហាញទិន្នន័យ ដើម្បីជួយ សម្រេចចិត្ត។ Excel ជាឧបករណ៍ទី ១ ដែល Data Analyst ប្រើ មុន SQL, Power BI និង Python។

  1. Ask — សួរសំណួរអាជីវកម្មឱ្យច្បាស់៖ «សាខាណា ផលិតផលណា រកចំណូលច្រើនបំផុតក្នុងត្រីមាសទី ១?»
  2. Prepare — ប្រមូលទិន្នន័យ (POS, CSV, Database, Google Form)
  3. Process — សម្អាត៖ ដកស្ទួន, ដកឃ្លា, កែប្រភេទទិន្នន័យ (មេរៀន ១៣–១៤)
  4. Analyze — PivotTable, SUMIFS, Statistics (មេរៀន ១៥–១៨)
  5. Share — Chart និង Dashboard (គម្រោងចុងក្រោយ)
  6. Act — ផ្តល់អនុសាសន៍៖ «បន្ថែមស្តុក Latte នៅបាត់ដំបង»

មើលចម្លើយ

Average = 5110 ÷ 7 = $730 · Median = $360។ គួររាយការណ៍ Median ព្រោះប្រាក់ខែ $3000 (អ្នកគ្រប់គ្រង) ជា Outlier ដែលទាញ Average ឡើងខ្ពស់ជាងបុគ្គលិក ៦ នាក់ក្នុងចំណោម ៧។

មើលចម្លើយ

ចំណេញ = (2.8 − 1) × 1500 − 1800 = $900 · Break-even = 1800 ÷ 1.8 = 1000 កែវ។

មេរៀន ១៨Data Model, Power Pivot & DAX

ពេលមានតារាងច្រើន (Sales, Products, Branches, Calendar) កុំបញ្ចូលគ្នាដោយ XLOOKUP រាប់សែនជួរ — ប្រើ Data Model ហើយភ្ជាប់ Relationship ដូច Database (Star schema)។

  1. Load Table នីមួយៗទៅ Data Model (Power Query → Close & Load To → ធីក Add this data to the Data Model)
  2. Power Pivot → Manage → Diagram View → អូស Products[Product] ទៅ Sales[Product]
  3. បង្កើត Measures ដោយ DAX (Power Pivot → Measures → New Measure)
  4. PivotTable ពី Data Model → ប្រើ Field ពីតារាងផ្សេងៗរួមគ្នា
💡 រៀន DAX ក្នុង Excel = ត្រៀមខ្លួនសម្រាប់ Power BI ព្រោះប្រើភាសា និង Data Model ដូចគ្នា។

✍️ លំហាត់ ១៨

សរសេរ Measure ៖ (ក) ចំនួនការកុម្ម៉ង់ (ខ) តម្លៃមធ្យមក្នុងមួយការកុម្ម៉ង់ (Average Order Value)។
