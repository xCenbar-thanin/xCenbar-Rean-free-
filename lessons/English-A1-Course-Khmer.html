២. កម្រិត A1 — Beginner (អ្នកចាប់ផ្តើម)

A1 ជាកម្រិត ដំបូងបំផុត៖ អ្នកយល់ និងប្រើ ពាក្យ និងឃ្លាសាមញ្ញៗប្រចាំថ្ងៃ ដើម្បីបំពេញតម្រូវការមូលដ្ឋាន ណែនាំខ្លួន សួរ និងឆ្លើយអំពីព័ត៌មានផ្ទាល់ខ្លួន (រស់នៅឯណា ស្គាល់អ្នកណា មានអ្វី) — ពេលអ្នកម្ខាងទៀតនិយាយយឺត និងច្បាស់។

✅ ចប់វគ្គនេះ អ្នកអាច (Can-do)

  • កុម្ម៉ង់ម្ហូប/ភេសជ្ជៈ និងទិញរបស់ងាយៗ

Countable [C] vs Uncountable [U]

some / any

some = ខ្លះ (ប្រយោគវិជ្ជមាន + សំណើគួរសម) · any = (សំណួរ និងបដិសេធ)។ ប្រើជាមួយ [U] និង [C] ពហុវចនៈ។

Would you like some tea?
អ្នកចង់ផឹកតែបន្តិចទេ?

like = ចូលចិត្ត (ជានិច្ច)៖ I like fish. · would like ('d like) = ចង់បាន (ឥឡូវ — គួរសមជាង want)៖ I'd like the fish, please.
