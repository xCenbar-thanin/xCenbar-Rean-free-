១. Software Engineering ជាអ្វី?

Software Engineering = អនុវត្តវិធីសាស្ត្រវិស្វកម្ម (ផែនការ · រចនា · សាក · ថែទាំ) ដើម្បីបង្កើត Software ធំ ត្រឹមត្រូវ ទាន់ពេល និងងាយថែទាំ ជាក្រុម — មិនមែនត្រឹមតែ «សរសេរកូដ» ទេ។ វគ្គនេះមាន SDLC · Requirements · Agile/Scrum · UML · Architecture · Clean code & SOLID · Design patterns · Git workflow · Testing & TDD · CI/CD · គ្រប់គ្រងគម្រោង — ជាមួយកូដ Python ដំណើរការពិត។

✍️ លំហាត់ ១

ក្រសួងមួយត្រូវការប្រព័ន្ធបង់ពន្ធ ដែលច្បាប់កំណត់ច្បាស់ ប្តូរតិច។ Startup មួយធ្វើ App ថ្មី មិនដឹងអតិថិជនចូលចិត្តអ្វី។ ជ្រើស Model សម្រាប់ទាំងពីរ។

មើលចម្លើយ

ក្រសួង៖ Waterfall/V-Model (តម្រូវការច្បាស់ ត្រូវការឯកសារ និង Test ពេញ)។ Startup៖ Agile/Scrum (ចេញ MVP លឿន ស្តាប់ Feedback ហើយកែ)។

✍️ លំហាត់ ១.២

រាយដំណាក់កាល SDLC តាមលំដាប់។

មើលចម្លើយ

Planning → Requirements → Design → Implementation → Testing → Deployment → Maintenance។

✍️ លំហាត់ ១.៣

មើលចម្លើយ

ច្រើនដង (រាប់សិប ដល់រាប់រយដង) — ព្រោះត្រូវកែ Design, Code, Test, Deploy ឡើងវិញ និងប៉ះពាល់អតិថិជន។

✍️ លំហាត់ ១.៤

App ធនាគារ ត្រូវការ Maintenance ប្រភេទណាខ្លះ?

មើលចម្លើយ

Corrective (កែ Bug) · Adaptive (iOS ថ្មី ច្បាប់ថ្មី) · Perfective (មុខងារថ្មី) · Preventive (Refactor, Security patch)។

មើលចម្លើយ

As a អ្នកលក់ក្នុងផ្សារ, I want បង្ហាញ KHQR ដែលមានចំនួនប្រាក់រួច, so that អតិថិជនបង់លឿន មិនច្រឡំចំនួន. AC៖ Given ខ្ញុំវាយ 12,500៛ When ចុច «បង្កើត QR» Then QR បង្ហាញចំនួន 12,500៛ ហើយជូនដំណឹងពេលទទួលប្រាក់។

✍️ លំហាត់ ២.២

បំបែក Functional vs Non-functional៖ «Login ដោយ OTP» · «Page load < 2s» · «Export PDF» · «Uptime 99.9%»

មើលចម្លើយ

Functional៖ Login OTP, Export PDF · Non-functional៖ Load < 2s, Uptime 99.9%។

✍️ លំហាត់ ២.៣

សរសេរ Acceptance criteria (Given/When/Then) សម្រាប់ Login ខុស ៣ ដង។

មើលចម្លើយ

Given អ្នកប្រើវាយពាក្យសម្ងាត់ខុស ២ ដងរួច · When ខុសលើកទី ៣ · Then គណនីត្រូវចាក់សោ ១៥ នាទី ហើយបង្ហាញសារ។

មេរៀន ១១CI/CD & DevOps

💡 CI (Continuous Integration) = Merge ញឹក + Test ស្វ័យប្រវត្តិ · CD (Delivery/Deployment) = ត្រៀម/ដាក់ Production ស្វ័យប្រវត្តិ។ ពាក្យ DevOps ពេញនិយមពីឆ្នាំ 2009 (Patrick Debois)។ មើលវគ្គ Docker + CI/CD។

✍️ លំហាត់ ១១

ហេតុអ្វី CI ត្រូវដំណើរការលើ Pull request មុន Merge?

មើលចម្លើយ

✍️ លំហាត់ ១១.២

Pipeline CI/CD សាមញ្ញ មានជំហានអ្វីខ្លះ?

មើលចម្លើយ

Checkout → Install → Lint → Test → Build → Deploy Staging → (Approve) → Production។

✍️ លំហាត់ ១១.៣
