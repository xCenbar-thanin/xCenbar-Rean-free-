១. Deep learning — អ្នកណាបង្កើត?

💡 AI មានដែនកំណត់៖ អាចខុស (Hallucination) មាន Bias ពីទិន្នន័យ និងប៉ះពាល់ឯកជនភាព។ ប្រើ AI ដោយ ទទួលខុសត្រូវ — ពិនិត្យការពិត កុំបញ្ចូលទិន្នន័យសម្ងាត់ និងគោរពច្បាប់ និងសិទ្ធិអ្នកនិពន្ធ។

Deep learning = Machine learning ដោយ Neural networks ច្រើនស្រទាប់ ដែលរៀនលក្ខណៈដោយខ្លួនឯងពីរូបភាព សំឡេង និងអក្សរ។ វគ្គនេះកសាង Neuron, Backpropagation, Optimizers, CNN (រូបភាព), RNN/LSTM, Embeddings និង Attention/Transformer — Code ដោយ NumPy រត់ពិត (ងាយយល់ពីខាងក្នុង) និងឧទាហរណ៍ PyTorch។

LLM ទស្សន៍ទាយ Token បន្ទាប់ ពី Probability។ Prompt៖ «រាជធានីរបស់កម្ពុជាគឺ …» — Temperature ទាប = ជាប់លាប់ · ខ្ពស់ = ច្នៃប្រឌិត/ចៃដន្យ។

RAG = ស្វែងរកឯកសារពាក់ព័ន្ធមុន រួចដាក់ក្នុង Prompt ដើម្បីឲ្យ LLM ឆ្លើយផ្អែកលើការពិត។ ឯកសារគំរូ ៨ (TF-IDF + Cosine similarity)។
