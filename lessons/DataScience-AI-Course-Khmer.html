🧩 របៀប Code ជំហានៗ
  1. np.array — Array ប្រភេទតែមួយ រក្សាក្នុង Memory ជាប់គ្នា → គណនាលឿន។
  2. Vectorization៖ qty * price គុណគ្រប់ធាតុ ដោយមិនបាច់ for loop។
  3. Boolean mask qty[qty > 20] — ត្រងទិន្នន័យ។
  4. axis=1 = តាមជួរ (ហាងនីមួយៗ) · axis=0 = តាម Column (ទំនិញនីមួយៗ)។
  5. Broadcasting៖ Array (3,4) × (4,) — NumPy ពង្រីក prices ឲ្យគ្រប់ជួរ ស្វ័យប្រវត្តិ។

🧩 របៀប Code ជំហានៗ
  1. Mean (មធ្យម) ងាយរងឥទ្ធិពល Outlier · Median (តម្លៃកណ្តាល) មាំជាង → ប្រាក់ខែ/តម្លៃផ្ទះ ប្រើ Median។

  4. Histogram — មើលរាងទិន្នន័យ (Distribution) · axvline គូសបន្ទាត់ mean/median។

🧩 របៀប Code ជំហានៗ
  1. A/B test៖ ចែកអតិថិជនដោយចៃដន្យ A (ចាស់) / B (ថ្មី) ហើយប្រៀបធៀបលទ្ធផល។
  2. Null hypothesis H₀៖ "គ្មានភាពខុសគ្នា" · p-value = ប្រូបាប៊ីលីតេឃើញភាពខុសគ្នាធំប៉ុណ្ណេះ ប្រសិនបើ H₀ ពិត។
  3. p < 0.05 → បដិសេធ H₀ (មានន័យស្ថិតិ) · ប៉ុន្តែត្រូវមើល ទំហំផលប៉ះពាល់ (CI) ដែរ — តើ +$0.3 មានតម្លៃអាជីវកម្មទេ?
  4. ttest_ind(equal_var=False) — Welch t-test សម្រាប់មធ្យម ២ ក្រុម · chi2_contingency — សម្រាប់ Category។
  5. កុំ "មើល p-value រាល់ថ្ងៃ ហើយឈប់ពេលល្អ" (p-hacking) — កំណត់ទំហំ Sample មុន។

  3. Accuracy = ត្រូវ/សរុប · Precision = ក្នុងចំណោមអ្នកដែលទាយថា "ត្រឡប់" ត្រូវប៉ុន្មាន · Recall = ក្នុងចំណោមអ្នកត្រឡប់ពិត ចាប់បានប៉ុន្មាន។
  4. Decision tree — ច្បាប់ if/else ដែលមនុស្សអានបាន (export_text) · max_depth ការពារ Overfitting។
  5. predict_proba — ប្រូបាប៊ីលីតេ (ប្រើកំណត់ Threshold — សាកក្នុង Data Lab Pro)។

✍️ លំហាត់ ១៣

App រកការក្លែងបន្លំកាត (Fraud) — គួរផ្តោតលើ Precision ឬ Recall?

មើលចម្លើយ

🧩 របៀប Code ជំហានៗ
  1. Overfitting៖ Model ស្មុគស្មាញពេក "ទន្ទេញ" Train (≈100%) តែ Test ធ្លាក់ · Underfitting៖ សាមញ្ញពេក ខុសទាំងពីរ។
  2. Cross-validation (5-fold)៖ ចែកទិន្នន័យ ៥ ចំណែក រៀន ៤ ពិនិត្យ ១ ផ្លាស់ប្តូរ ៥ ដង → ពិន្ទុទុកចិត្តជាង Split តែមួយ។
  3. Pipeline make_pipeline(StandardScaler(), LogisticRegression()) — Preprocessing + Model ជាមួយគ្នា → ជៀស Data leakage។
  4. Random Forest — ដើមឈើ ២០០ បោះឆ្នោត → មាំជាងដើមតែមួយ · feature_importances_ ប្រាប់ថា visits_per_month សំខាន់បំផុត។
  5. ដំណើរការពិត៖ Baseline → Model សាមញ្ញ → Model ស្មុគស្មាញ · ជ្រើសតាម CV មិនមែន Test (រក្សា Test សម្រាប់ចុងក្រោយ)។
