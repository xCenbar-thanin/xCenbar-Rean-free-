២. របៀបដំឡើង Word (និងភ្ជាប់ជាមួយ VS Code)

⚠️ Word មិនដំឡើងក្នុង VS Code ទេ។ វាជាកម្មវិធីក្នុង Microsoft 365។ VS Code ប្រើតែពេលអ្នក សរសេរកូដ៖ បង្កើត Word Add-in, បង្កើតឯកសារ .docx ដោយ Python ឬបំប្លែង Markdown → Word ដោយ Pandoc។

ជំហានទី ១: ដំឡើង Word

  1. ឥតគិតថ្លៃ៖ office.com → Sign in → Word for the web
  2. ពេញលេញ៖ Microsoft 365 (ឬគណនីសាលា) → office.com → Install apps → ដំឡើង → Sign in
  3. ទូរស័ព្ទ៖ Microsoft Word ឬ Microsoft 365 Copilot app
  4. វាយខ្មែរ៖ Windows Settings → Time & Language → Language → Add Khmer (Keyboard NiDA ឬ Khmer Unicode) · ប្តូរភាសា Win+Space ឬ Alt+Shift
  5. Font ខ្មែរ Unicode៖ Khmer OS Battambang (អត្ថបទ), Khmer OS Muol Light (ចំណងជើងផ្លូវការ), Kantumruy Pro, Noto Sans Khmer · File → Options → Save → Embed fonts

ជំហានទី ២ (ជម្រើសសម្រាប់អ្នកសរសេរកូដ): VS Code

  1. VS Code + Node.js → Extension Office Add-ins Development Kit → Create Add-in → Word
  2. Python៖ pip install python-docx ដើម្បីបង្កើតលិខិត/របាយការណ៍ពីទិន្នន័យ
  3. Markdown → Word៖ ដំឡើង Pandoc → pandoc report.md -o report.docx --reference-doc=template.docx

✍️ លំហាត់ ១

អ្នកបានវាយ Enter ៥ ដងដើម្បីទៅទំព័រថ្មី។ ហេតុអ្វីវាជាបញ្ហា ហើយកែដូចម្តេច?

មេរៀន ៣Styles & Headings ⭐ (សំខាន់បំផុត)

Style = Format ដែលមានឈ្មោះ។ ប្រើ Style ជំនួសការ Format ដោយដៃ ដើម្បី៖ TOC ស្វ័យប្រវត្តិ, Navigation Pane, លេខរៀងជំពូក, ប្តូររចនាប័ទ្មទាំងឯកសារក្នុងពេលតែមួយ, និង Accessibility។

  1. ជ្រើសចំណងជើង → Home → Styles → Heading 1 (Ctrl+Alt+1)
  2. កែ Style៖ ចុចស្តាំលើ Heading 1 → Modify → Font Khmer OS Muol Light 16pt, ពណ៌, Spacing Before 18 / After 6 → ធីក New documents based on this template (បើចង់ប្រើគ្រប់ពេល)
  3. ឬ Format ចំណងជើងមួយតាមចិត្ត → ចុចស្តាំ Heading 1 → Update Heading 1 to Match Selection
  4. View → Navigation Pane៖ អូស Heading ដើម្បីផ្លាស់ទីជំពូកទាំងមូល
  5. Design → Style Set / Colors / Fonts៖ ប្តូររូបរាងទាំងឯកសារ

✍️ លំហាត់ ៣

ឯកសារ ៤០ ទំព័រ ចំណងជើងទាំងអស់ Format ដោយដៃ (Bold 14pt)។ តើធ្វើដូចម្តេចឱ្យវាក្លាយជា Heading 1 ទាំងអស់ឱ្យលឿន?

មេរៀន ៤Lists & Tables

  • Bullets / Numbering៖ Tab = ចុះកម្រិត · Shift+Tab = ឡើងកម្រិត · ចុចស្តាំលេខ → Restart at 1 / Continue Numbering
  • Insert → Table · Table Design → Style · Layout → Repeat Header Rows (ក្បាលតារាងលើគ្រប់ទំព័រ)
  • Layout → AutoFit Window, Distribute Columns, Merge/Split Cells, Text Direction
  • Table Properties → Row → ដោះធីក Allow row to break across pages
  • Layout → Formula (=SUM(ABOVE)) · Sort · Convert Text to Table

✍️ លំហាត់ ៤

តារាងតម្លៃ ៣ ទំព័រ — ក្បាលតារាងបង្ហាញតែទំព័រទី ១ ហើយជួរខ្លះបែកពាក់កណ្តាលទៅទំព័របន្ទាប់។ កែដូចម្តេច?

មើលចម្លើយ
  1. ជ្រើសជួរក្បាល → Table Layout → Repeat Header Rows
  2. ជ្រើសតារាងទាំងមូល → Table Properties → Row → ដោះធីក Allow row to break across pages
