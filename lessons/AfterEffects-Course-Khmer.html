១. After Effects ជាអ្វី? អ្នកណាបង្កើត?

  1. adobe.com → Adobe Account → Plan (After Effects តែមួយ ឬ Creative Cloud Pro) · Free trial 7 ថ្ងៃ · តម្លៃសិស្ស

មេរៀន ១ Composition & Layers

  1. Ctrl+N New Composition → Preset HD 1920×1080 25fps (ឬ 1080×1920 សម្រាប់ Reels) · Duration 10s · Background ខ្មៅ
  2. Import (Ctrl+I) Logo .ai/.psd → Composition – Retain Layer Sizes (រក្សា Layers ដាច់ៗ)
  3. ដាក់ឈ្មោះ Layers (Enter) · ដាក់ពណ៌ Label · Lock 🔒 ផ្ទៃខាងក្រោយ
  4. [ / ] រំកិល In/Out ទៅ Playhead · Alt+[ / ] កាត់ (Trim) · Ctrl+Shift+D Split layer
💡 លំដាប់ Layers = លំដាប់គូរ៖ Layer លើ ក្នុង Timeline គ្របលើ Layer ក្រោម (ដូច Photoshop)។

មេរៀន ២ Keyframes & Transform

ចុច ⏱️ Stopwatch ក្បែរ Property → Keyframe ទី ១ · រំកិល Playhead → ប្តូរតម្លៃ → Keyframe ថ្មីបង្កើតដោយស្វ័យប្រវត្តិ។ J/K លោតទៅ Keyframe មុន/បន្ទាប់។

Position keyframes៖ 0s = [80, 135] → 1.5s = [400, 135] → 3s = [240, 60] (Linear — ល្បឿនថេរ ហើយផ្លាស់ទិសភ្លាមៗ)។ ចំណុចលឿង = Keyframes លើក្រាហ្វ X៖

✍️ លំហាត់ ២

ធ្វើ «Pop-in»៖ Scale 0% → 110% → 100% ក្នុង 0.5 វិនាទី។ ត្រូវមាន Keyframes ប៉ុន្មាន? ដាក់នៅពេលណា?

មើលចម្លើយ

៣ Keyframes៖ 0.00s = 0%, 0.30s = 110% (Overshoot), 0.50s = 100% (តាំងលំនឹង)។ បន្ទាប់មក ជ្រើសទាំងអស់ → F9 Easy Ease (មេរៀន ៣)។

មេរៀន ៣ Easing & Graph Editor

វត្ថុពិតមិនចាប់ផ្តើម/ឈប់ភ្លាមៗទេ។ Easy Ease (F9) ធ្វើឱ្យល្បឿនចាប់ផ្តើមយឺត ហើយបញ្ចប់យឺត។ Shift+F9 Ease In · Ctrl+Shift+F9 Ease Out។ បើក Graph Editor (Shift+F3) ដើម្បីកែ Speed/Value graph។

Keyframes ដូចមេរៀន ២ ប៉ុន្តែ Easy Ease — មើលក្រាហ្វជារាងអក្សរ S (យឺត → លឿន → យឺត)៖

Graphមើល/កែ
Value graphតម្លៃតាមពេល — ខ្សែ S = Ease
Speed graphល្បឿន — ភ្នំខ្ពស់ចង្អុល = Snappy (ទាញ Handle ឱ្យវែង 70–90%)
Separate DimensionsPosition X/Y ដាច់ៗ ដើម្បីកែ Graph នីមួយៗ

✍️ លំហាត់ ៣

Motion designer និយាយថា «ចលនាមើលទៅ Robot»។ អ្នកកែអ្វី?

មើលចម្លើយ

Keyframes ប្រហែលជា Linear → ជ្រើស → F9 Easy Ease → Graph Editor → Speed graph → ទាញ Influence ឱ្យខ្លាំង (ឧ. Out 80% / In 80%) ដើម្បីចលនា «ចេញលឿន ចូលទន់»។ បន្ថែម Overshoot តូចៗ (Scale 105% មុន 100%) និង Motion blur (🌀) ឱ្យមានជីវិត។

មេរៀន ៤ Shape Layers & Trim Paths

Shape layers ជា Vector (មិនបែកពេល Scale)។ Contents មាន Path, Fill, Stroke និង Operators៖ Trim Paths (គូរបន្ទាត់បន្តិចម្តងៗ), Repeater, Round Corners, Wiggle Paths, Offset Paths។

✍️ លំហាត់ ៤

បង្កើត Loader រង្វង់ (Spinner)៖ Shape ellipse + Stroke មិនមាន Fill។ ប្រើ Operator/Property អ្វី?

មើលចម្លើយ

Add → Trim Paths៖ Start 0%, End 25% · Keyframe Offset 0° → 360° ក្នុង 1s (Linear) ហើយ Expression loopOut() លើ Offset ដើម្បីវិលជារៀងរហូត · Stroke Line Cap = Round។

មេរៀន ៥ Text Animation: Animators & Range Selector

Text layer → Animate ▸ (Position, Opacity, Scale, Tracking...) → បង្កើត Animator + Range Selector។ Keyframe Offset ឬ Start ដើម្បីឱ្យតួអក្សរនីមួយៗចលនាតាមលំដាប់។ Effects & Presets → Animation Presets → Text មាន Presets ច្រើន។ AE 26 អាច Animate Variable font axes (Weight, Width)។

💡 អក្សរខ្មែរ៖ ជ្រើស Font ខ្មែរ Unicode (Kantumruy Pro, Battambang, Noto Sans Khmer) និងប្រើ South Asian and Middle Eastern Text Engine (Preferences → Type) ដើម្បីឱ្យជើងអក្សរ/ស្រៈបង្ហាញត្រឹមត្រូវ។ ការ Animate «តាមតួអក្សរ» អាចបំបែកស្រៈ — ប្រើ Based On: Words ឬ Lines សម្រាប់ខ្មែរ។

✍️ លំហាត់ ៥

ធ្វើឱ្យអក្សរ «Typewriter» (លេចម្តងមួយតួ) ដោយមិនប្រើ Preset។

មើលចម្លើយ

Animate → Opacity = 0% · Range Selector → Advanced → Shape: Square, Smoothness 0% · Keyframe Start 0% → 100% (Linear) ក្នុងរយៈពេលតាមប្រវែងអត្ថបទ។ ឬ Expression លើ Source Text (មេរៀន ៩)៖ value.substr(0, Math.floor(time*12))។

មេរៀន ៦ Masks & Track Mattes

Mask (Pen G / Rectangle Q លើ Layer ដែលបានជ្រើស) — កំណត់ផ្នែកមើលឃើញ, Feather, Expansion, Mask Path keyframes (M)។ Track Matte — Layer មួយ (Matte) កំណត់ភាពមើលឃើញនៃ Layer មួយទៀត៖ Alpha Matte ឬ Luma Matte (AE ទំនើបអាចជ្រើស Matte layer ណាមួយដោយ Pick whip)។
