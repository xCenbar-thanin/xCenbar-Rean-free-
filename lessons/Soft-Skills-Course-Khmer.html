១. Soft Skills ជាអ្វី? មកពីណា?

Soft skills = ជំនាញធ្វើការជាមួយមនុស្ស និងគ្រប់គ្រងខ្លួនឯង — ការទំនាក់ទំនង ការងារជាក្រុម ការគ្រប់គ្រងពេល ការគិតដោះស្រាយបញ្ហា បញ្ញាអារម្មណ៍ ភាពជាអ្នកដឹកនាំ។ Hard skills (Code, គណនេយ្យ, ភាសា) ជួយឲ្យ ទទួលបានការងារ — Soft skills ជួយឲ្យ រក្សាការងារ និងឡើងតំណែង។ វគ្គនេះមានឧទាហរណ៍ក្នុងបរិបទសាលា និងកន្លែងធ្វើការនៅកម្ពុជា។
