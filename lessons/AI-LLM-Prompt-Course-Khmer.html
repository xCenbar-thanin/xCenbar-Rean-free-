១. LLM & Generative AI — អ្នកណាបង្កើត?

💡 AI មានដែនកំណត់៖ អាចខុស (Hallucination) មាន Bias ពីទិន្នន័យ និងប៉ះពាល់ឯកជនភាព។ ប្រើ AI ដោយ ទទួលខុសត្រូវ — ពិនិត្យការពិត កុំបញ្ចូលទិន្នន័យសម្ងាត់ និងគោរពច្បាប់ និងសិទ្ធិអ្នកនិពន្ធ។

Large Language Model (LLM) = Transformer ធំ ដែលរៀនពីអក្សររាប់ពាន់លានពាក្យ ដើម្បី ទាយ Token បន្ទាប់ — ហើយអាចសរសេរ បកប្រែ សង្ខេប សរសេរ Code និងវែកញែក។ វគ្គនេះបង្រៀន Prompt engineering ពីមូលដ្ឋានដល់ខ្ពស់ (ប្រើបានភ្លាមជាមួយ Claude, ChatGPT, Gemini — គ្មាន Code) និង RAG, Tool use, Agents, Evaluation សម្រាប់អ្នកអភិវឌ្ឍ (Code Python តិចតួច)។
