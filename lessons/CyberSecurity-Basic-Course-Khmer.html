១. Cyber Security ជាអ្វី? អ្នកណាបង្កើត?

⚠️ វគ្គនេះសម្រាប់ ការពារ (Defensive)។ ការចូលប្រព័ន្ធ/គណនីរបស់អ្នកដទៃ ឬស្កេន/វាយប្រហារបណ្តាញ ដោយគ្មានការអនុញ្ញាតជាលាយលក្ខណ៍អក្សរ គឺខុសច្បាប់ ហើយអាចបង្កគ្រោះថ្នាក់ពិត។ ហាត់តែលើឧបករណ៍ផ្ទាល់ខ្លួន Lab ឬ CTF ស្របច្បាប់ប៉ុណ្ណោះ។

Cyber security = ការការពារ មនុស្ស ឧបករណ៍ គណនី និងទិន្នន័យ ពីការវាយប្រហារតាម Internet។ កម្រិតដំបូងនេះសម្រាប់ គ្រប់គ្នា (សិស្ស និស្សិត ឪពុកម្តាយ) — គ្មាន Code — រៀនការពារខ្លួនពី Phishing, ការបោកប្រាស់តាម Telegram/Facebook, ការលួចគណនី និង Ransomware។

២. ត្រៀមខ្លួន

  1. ឧបករណ៍ផ្ទាល់ខ្លួន (ទូរស័ព្ទ/កុំព្យូទ័រ) — យើងនឹងពង្រឹងសុវត្ថិភាពវាតាមមេរៀន។
  2. Password manager (Bitwarden, 1Password ឬ Google/Apple Password manager)។
  3. កម្មវិធី Authenticator (Google/Microsoft Authenticator) សម្រាប់ MFA។
  4. ប្រើ Cyber Lab នៅចុងវគ្គ ដើម្បីហាត់សម្គាល់ Phishing និងពិនិត្យពាក្យសម្ងាត់។
