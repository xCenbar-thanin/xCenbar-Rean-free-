មេរៀន ០ស្គាល់ HTML

១. HTML ជាអ្វី?

HTML មកពី HyperText Markup Language។ វាជា «ភាសាសម្គាល់» (markup language) សម្រាប់កំណត់រចនាសម្ព័ន្ធ និងខ្លឹមសាររបស់ទំព័រគេហទំព័រ ដូចជា ចំណងជើង អត្ថបទ រូបភាព តំណភ្ជាប់ តារាង និងទម្រង់បញ្ចូលទិន្នន័យ។

  • HyperText = អត្ថបទដែលអាចចុចតភ្ជាប់ទៅទំព័រ ឬឯកសារផ្សេងបាន (link)។
  • Markup = ការដាក់សញ្ញាសម្គាល់ (tag) ជុំវិញខ្លឹមសារ ដើម្បីប្រាប់ browser ថាអ្វីជាចំណងជើង អ្វីជាប្រការ។
⚠️ HTML មិនមែនជាភាសាសរសេរកម្មវិធី (programming language) ទេ ព្រោះវាមិនមាន logic ដូចជា if / loop ។ វាគ្រាន់តែរៀបចំរចនាសម្ព័ន្ធខ្លឹមសារប៉ុណ្ណោះ។

២. អ្នកបង្កើត HTML

Sir Tim Berners-Lee (ទីម ប៊ឺណឺស-លី) អ្នករូបវិទ្យាជនជាតិអង់គ្លេស ដែលធ្វើការនៅ CERN (អង្គការស្រាវជ្រាវនុយក្លេអ៊ែរអឺរ៉ុប) ប្រទេសស្វីស។ គាត់បានស្នើគំនិត World Wide Web ក្នុងឆ្នាំ ១៩៨៩ ហើយបានបោះផ្សាយការពិពណ៌នា HTML ដំបូងក្នុងឆ្នាំ ១៩៩១ ដើម្បីឲ្យអ្នកស្រាវជ្រាវចែករំលែកឯកសារតភ្ជាប់គ្នាបានយ៉ាងងាយ។ ក្រោយមក ស្តង់ដារ HTML ត្រូវបានថែរក្សាដោយអង្គការ W3C និង WHATWG។

៤. គេប្រើ HTML សម្រាប់ធ្វើអ្វី?

  • បង្កើតគេហទំព័រ (website) គ្រប់ប្រភេទ៖ ព័ត៌មាន ហាងលក់ អនឡាញ ប្លក់ ផលប័ត្រផ្ទាល់ខ្លួន
  • បង្កើតទម្រង់បញ្ចូលទិន្នន័យ៖ ចុះឈ្មោះ ចូលគណនី ទំនាក់ទំនង
  • ធ្វើជាមូលដ្ឋានសម្រាប់ Web App និង Progressive Web App
  • សរសេរ Email ជាទម្រង់ HTML (newsletter)
  • ជាមូលដ្ឋានរបស់ App ប្រភេទ hybrid ដូចជា Ionic, Cordova និងសូម្បីតែ UI ខ្លះក្នុង Desktop App (Electron)
  • បង្ហាញឯកសារ និងសៀវភៅអេឡិចត្រូនិក (EPUB ប្រើ HTML ផង)

៥. HTML ជាមួយ CSS និង JavaScript

CSSរចនា ពណ៌ ទំហំ ប្លង់ថ្នាំលាប និងការតុបតែង

៦. ទម្រង់ទូទៅនៃធាតុ HTML (Element)

  • Opening tag = <p> ចាប់ផ្តើមធាតុ
  • Closing tag = </p> បញ្ចប់ធាតុ (មាន /)
  • Attribute = ព័ត៌មានបន្ថែម ដាក់ក្នុង opening tag ជាទម្រង់ ឈ្មោះ="តម្លៃ"
  • Content = អ្វីដែលនៅចន្លោះ opening និង closing tag
  • ធាតុខ្លះគ្មាន closing tag ហៅថា void element ដូចជា <br>, <img>, <hr>, <input>

💡 HTML មិនចាំបាច់ install ទេ! អ្នកត្រូវការតែ (១) កម្មវិធីសរសេរ code (Text Editor) ដូចជា Visual Studio Code និង (២) Browser ដូចជា Chrome, Edge, Firefox។ ខាងក្រោមជាជំហានរៀបចំ VS Code សម្រាប់សរសេរ HTML។

ជំហានទី ១៖ ទាញយក និងដំឡើង VS Code

  1. បើក browser ហើយទៅ code.visualstudio.com
  2. ចុច Download ជ្រើសរើសតាមប្រព័ន្ធរបស់អ្នក (Windows / macOS / Linux)
  3. បើក file ដែលទាញយក (ឧ. VSCodeUserSetup.exe) ហើយចុច Next
  4. ក្នុងជំហាន «Select Additional Tasks» សូមធីក ✅ Add "Open with Code" action និង ✅ Add to PATH
  5. ចុច Install រួចចុច Finish

ជំហានទី ២៖ បង្កើត Folder និង File HTML

  1. បង្កើត folder ថ្មីក្នុងកុំព្យូទ័រ ឈ្មោះ html-lesson
  2. បើក VS Code ហើយចុច File → Open Folder… ជ្រើសរើស folder នោះ
  3. ចុចរូប New File ក្បែរឈ្មោះ folder ក្នុង Explorer ហើយដាក់ឈ្មោះ index.html (ត្រូវបញ្ចប់ដោយ .html)
  4. ក្នុង file នោះ វាយ ! រួចចុច Tab → VS Code នឹងបង្កើតរចនាសម្ព័ន្ធ HTML មូលដ្ឋានឲ្យដោយស្វ័យប្រវត្តិ (Emmet)
  5. ចុច Ctrl + S ដើម្បី Save (Mac៖ Cmd + S)

ជំហានទី ៣៖ មើលលទ្ធផលក្នុង Browser

វិធីទី ១ (ធម្មតា)៖ ចុចពីរដងលើ file index.html ក្នុង folder ដើម្បីបើកក្នុង browser។

វិធីទី ២ (ល្អបំផុត)៖ ដំឡើង Live Server ដើម្បីឲ្យទំព័រ refresh ស្វ័យប្រវត្តិរាល់ពេល Save៖

  1. ចុចរូប Extensions នៅរបារខាងឆ្វេង (ឬ Ctrl+Shift+X)

  4. ចុចខាងស្តាំលើ file index.html ជ្រើស Open with Live Server (ឬចុច Go Live នៅរបារខាងក្រោម)

ឯកសារ HTML ទាំងអស់មានរចនាសម្ព័ន្ធមូលដ្ឋានដូចគ្នា៖

ធាតុពន្យល់

<html>ធាតុឫស (root) ដែលគ្របដណ្តប់ទំព័រទាំងមូល។ lang="km" ប្រាប់ថាភាសាខ្មែរ

<meta charset="UTF-8">កំណត់ encoding ឲ្យបង្ហាញអក្សរខ្មែរបានត្រឹមត្រូវ (សំខាន់ណាស់!)

<meta name="description"…>ការពិពណ៌នាខ្លី ដែល Google បង្ហាញក្នុងលទ្ធផលស្វែងរក (SEO)
<style>ដាក់ CSS ក្នុង head (ឬភ្ជាប់ File ដោយ <link rel="stylesheet">)

<body>ខ្លឹមសារទាំងអស់ដែលអ្នកប្រើមើលឃើញ

មេរៀន ៧បញ្ជី (List)

🏆 ផ្នែកទី ៣: ទំព័រ HTML កម្រិតអាជីព

លើកកម្រិតគម្រោងចុងក្រោយ ទៅជាទំព័រដែលក្រុមហ៊ុនពិតប្រាកដធ្វើ៖ SEO (meta description, Open Graph), Responsive លើទូរស័ព្ទ, Accessibility (skip link, label, alt, scope, aria), Performance (lazy loading, width/height) និង Form Validation ដោយ HTML សុទ្ធ។

✔ សាកល្បងរួច បើកលើអេក្រង់ទូរស័ព្ទ គ្មាន Error ធាតុទាំងអស់មាន label/alt ហើយ Form Validation ដំណើរការ។
